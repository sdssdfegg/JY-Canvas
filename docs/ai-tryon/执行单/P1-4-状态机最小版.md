## 1. 改动要求

### 1.1 新增 `server/ai-tryon/state-machine.js`（纯函数）
- 实现子集（其余 `ANALYZING`/`POSTPROCESSING`/`REPAIR_PENDING`/`RETRY_WAIT` 留位，契约已定义）：
  `CREATED → VALIDATING → READY_TO_GENERATE → GENERATING → EVALUATING → SUCCEEDED / FAILED / CANCELLED / NEEDS_REVIEW`
- `transition(task, event)`：返回新状态，非法转移**抛错**（不静默）。

### 1.2 铁律落位（state-machine.md §2）
- **持久化优先**：外部调用前先写状态 + attempt（依赖 P1-1）；
- **终态不静默覆盖**：SUCCEEDED/FAILED/CANCELLED/NEEDS_REVIEW 需新尝试时创建受关联新 attempt；
- **预算/重试检查在调用前**（供 P1-5 调用）：`checkBudgetBeforeCall(task)` 返回是否放行；
- **重试分类**：限流/网络/超时 → 有限指数退避；参数/权限 → 不自动重试；质量 → 仅策略允许时有限修复（具体重试动作在 P1-5）。
