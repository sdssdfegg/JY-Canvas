## 建议的最少覆盖（4 组起）

1. s01：标准体型正面站姿 + 白底产品图 + 单色合身款（基线参照组）
2. s02：非常规体型（如丰满/瘦小）+ 挂拍 + 格纹宽松款（臃肿敏感组）
3. s03：侧身/手臂遮挡姿态 + 真人穿着参考 + 深色印花款（遮挡与参考图类型组）
4. s04：浅色复杂图案 + 合身款（颜色与细节敏感组）
