# 人工评分规则（P0）

> 总纲 §7.2 指标定义的第一版落地。评分人：用户或指定复核人；每张结果图逐维打分，分数+依据写进结果目录的 `score.md`。
> 纪律：评分在看过指标计算结果**之前/之后各做一次**更好（防被数字锚定）；视觉模型自评分只作参考，不作唯一真值。

## 维度与打分（每维 0–2 分）

| 维度 | 0 分（失败） | 1 分（可修复） | 2 分（通过） | 对应失败标签 |
|---|---|---|---|---|
| 人体结构 | 身材/轮廓/姿态被明显改变 | 轻微变化，可局部恢复 | 身份/轮廓/姿态/裸露皮肤保留 | BODY_SHAPE_DRIFT |
| 服装轮廓/版型 | 胸部/肩/腰/衣身无依据膨胀，或版型明显错误 | 轻微臃肿/版型偏移 | 版型与参考一致，无鼓包空腔 | GARMENT_TOO_BULKY / FIT_TYPE_DRIFT |
| 颜色一致性 | 主色/色簇明显偏离参考 | 可校色修复的偏差 | 与参考一致（目视） | COLOR_SHIFT |
| 图案/细节 | 格纹/Logo/纽扣/领袖变形或缺失 | 细节轻微劣化 | 关键细节完整可辨 | PATTERN_DISTORTION / DETAIL_MISSING |
| 非编辑区 | 脸/手/头发/背景明显变化 | 轻微变化 | 非目标区域保持原样 | BACKGROUND_CHANGED / POSE_OCCLUSION_ERROR |
| 边缘/完整性 | 穿模/断裂/粘连/额外部件 | 边缘轻微瑕疵 | 边缘干净自然 | EDGE_ARTIFACT |

## 汇总分级（总纲 §10.2）

- **A 级（直接交付）**：六维全部 2 分；
- **B 级（可局部修复）**：无 0 分，且 1 分集中在颜色/边缘等可后处理维度；
- **C 级（重生成或人工复核）**：任一结构维度（人体/版型/完整性）0 分。

## 汇总指标（按组计算，写进 P0 退出报告）

- 臃肿失败率 = GARMENT_TOO_BULKY 得 0 分样本占比；
- 人体保真率 = 人体结构维度得 2 分占比；
- 关键细节通过率 = 图案/细节维度得 2 分占比；
- 非编辑区变化率 = 非编辑区维度 ≤1 分占比；
- 首次交付通过率 = A 级占比；
- 单张合格成本 =（总消耗金额）/ A 级张数；
- 失败可解释率 = 有明确标签的失败任务 / 全部失败任务。

阈值纪律：具体百分比阈值在 P0 基线完成后由用户设定；**不得在无样本数据时编造"提升 30%"类承诺**（总纲 §10.2）。
