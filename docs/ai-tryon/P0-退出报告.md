## 五、P0 关键裁定

1. **Mask 语义 = 无效（实测推定）** ⇒ 换装主路径走「双图 + 文本约束」，非编辑区保护用后处理，不建立在掩膜之上。掩膜通道保留不删，P3 复验门槛：精确掩膜 + 钉 seed ≥6 例，若非编辑区相对对照有 ≥1 分优势则改判 A/C。（`DECISIONS.md` D-06）
2. **TT2.5 渠道口径**：不走云枢，用第二个渠道 Origin `silent-tt25-line-06`；香蕉 Pro 走云枢 `silent-pro-line-01`。（D-07）
3. **结构化提示词有效** ⇒ 经 P1-7 模板系统落地，但**默认不挂载**（`DEFAULT_PROMPT_TEMPLATE_VERSION = null`），生效前须同批次 A/B 复验 + 用户目视确认。
4. **生产模型建议**：`nano-banana-pro`（耗时 41.9s vs 116.5s、稳定性 8/8 vs 7/8、画质 9.75 vs 8.86）⇒ **建议主线用香蕉 Pro**；TT2.5 在结构化提示词下质量可大幅弥补，作质量优先备选。
