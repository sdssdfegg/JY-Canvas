# ADR-002：Mask 语义有效性与人体保护主路径

> 状态：**草案**（2026-10-27 起草）｜ 上位：`docs/ai-tryon/升级实施方案-V11-电商换装能力升级.md`
> 依赖证据：`EVIDENCE.md` §三-A（E1 Mask 语义）/ §三-B（E2 双模型）/ §三-C（27 例六维评分）
> 格式：总纲 §14 七要素（背景/选项/证据/决定/代价/回滚/批准人）

## 背景

换装要「换掉衣服、保住人」。业界两条路线：① 掩膜约束路线——先出服装/人体掩膜，把编辑限制在掩膜区域内，非编辑区像素原样保留；② 语义编辑路线——不出掩膜，靠「双图输入 + 文本约束」让模型自行理解换哪部分、保留哪部分。

选哪条取决于一个**可测的事实**：中转/上游对 mask 参数到底遵不遵守语义。若遵守（掩膜有效），掩膜路线能硬保证非编辑区不动，值得投入掩膜生成（P3）；若不遵守（掩膜无效），掩膜只是徒增成本，应走语义编辑 + 原图恢复/合成。

此即本 ADR 被称为**生死题**的原因：它决定 P3 的形态与 P1/P2 的接口设计。

## 选项

- **A. 掩膜优先**：`mask` 参数被上游遵守 ⇒ 换装主路径走「生成/获取掩膜 → 掩膜约束编辑 → 非编辑区硬恢复」；P3 人体保护建立在掩膜之上；
- **B. 语义优先（兜底）**：`mask` 不产生可观测约束效应 ⇒ 主路径走「双图输入 + 文本约束」；非编辑区保护改用后处理（差异检测 / 原图合成），不依赖上游掩膜语义；
- **C. 双轨并行**：掩膜作为「能带就带」的可选增强，不作为主路径依赖。

## 证据（2026-10-26/27 实测）

### 1. 掩膜链路是接通的（不存在「发了被丢」）
- 探针侧：`scripts/ai-tryon/p0-probe.mjs:322-324` 以多部件上传 `form.append("mask", ...)`；
- 服务端：`server/channel.js:339/378` 在 TT2.5/换装多部件路径中 `appendUploadFile(form, "mask", params.maskFile, ...)`，掩膜文件一路转发至上游。

⇒ 若掩膜无效果，**不是接线问题，而是上游不消费该语义**。

### 2. E1 三模式对照（12 例，TT2.5 + Origin，全部 http 200）
| 模式 | 用例数 | 画质均分（/12） | 耗时区间 |
|---|---|---|---|
| 无掩膜（对照） | 4 | **9.50** | |
| 服装掩膜 `mask-garment.png` | 4 | 9.00 | |
| 人体掩膜 `mask-body.png` | 4 | 9.25 | |

- 三组差异 **≤0.5 分**，且**对照组（无掩膜）均值最高**；
- 跨 4 组样本逐张目视比对：**无任何一例呈现「掩膜组内非编辑区更干净」或「边界溢出更少」的可量化优势**。

### 3. 与 E2/评分的交叉印证
- 27 例全体均分 **9.30/12**，**A 级 0 张**（B=24 / C=3）；
- 最大瓶颈是**维度②「服装轮廓/版型」2 分率仅 4%**——失分主因是模型**「过设计」**（凭空添加参考图没有的部件：毛领/腰封/挎包/墨镜/长靴/荷叶边），而非「非编辑区被污染」；
- 若掩膜有效，维度⑤（非编辑区，67%）与维度⑥（边缘，78%）应显著优于对照——实测未见。

### 4. 方法论局限（如实记录，不得略过）
- 本轮使用**粗掩膜**（躯干椭圆，覆盖面≈全身）⇒ **灵敏度不足**，无法排除「精确掩膜在精细边界上有效」；
- 未钉 seed（上游 `seedSupport` 为 UNKNOWN，正是 E4 待测项）⇒ 无法分离「掩膜效应」与「随机波动」；
- 因此本 ADR 只能定到 **B（语义优先·兜底）为暂定主路径**，并把「精确掩膜 + 钉 seed 复验」列为 P3 入口条件，而非判它死刑。

## 决定（草案·暂定 B，留复验口）

**暂选 B（语义优先·兜底）**：基础换装主路径 = 双图输入 + 文本约束，**不依赖上游 mask 语义**；非编辑区保护在 P3 用后处理（差异检测/原图合成）实现，不建立在掩膜之上。

同时明确：
1. **不删掩膜通道**——P1-5 执行入口保留 `mask` 入参缝，P3 需要时可带；
2. P1-7 双分支句据此**固化到兜底分支**（已落地，`prompts/server/outfit-prompt-template.js` 模板 v2）；
3. **P3 入口条件（复验门槛）**：用**精确掩膜**（精确抠图，非椭圆）+ **钉 seed** 复跑 ≥6 例，若非编辑区维度相对对照有 ≥1 分优势，则本 ADR **修订为 A（或 C）**；否则维持 B；
4. **生产模型建议（待用户复核）**：E2/E5 两口径（画质 9.75 vs 8.86；耗时 41.9s vs 116.5s）同向指向 `nano-banana-pro`。⚠️ 评分为视觉模型自评，切换生产模型前须人工复核。

## 代价

- 放弃「掩膜硬保证」，非编辑区保护退化为**概率性 + 后处理**，P3 需自建差异检测/合成逻辑；
- 若上游日后修复 mask 语义，需按 §决定-3 重新评估（复验成本 ≈6 次额度）；
- 「过设计」问题（维度②96% 未满分）**不由本 ADR 解决**，归 P2 服装档案（约束版型/品类）与 P4 质量报告。

## 回滚

本 ADR 只影响**换装主路径的选择**，不改动现有生成链路；模板 v2 为新增版本且默认 `DEFAULT_PROMPT_TEMPLATE_VERSION=null`（默认不挂载）⇒ 不生效即等同回滚；v4.0 标签保底。

## 批准人

待用户（人类授权人）。批准条件：E4（seed/可复现性）+ E5（结构化提示词）结论补齐后，随 P0 退出报告一并审。
