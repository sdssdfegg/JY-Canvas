## 0. 背景

UI 规范化进入总纲 §9 共享面抽取队列。前三项已完成：V90 `TaskBadge`、V91 `DetailUploadZone`、V98 `AppSidebar`。本单抽第④项——**Modal 外壳扩散**。

现状测绘（起草日 `git grep` 实测）：全仓仍有 **15 处 bespoke `div.modalLayer + section onMouseDown=stopPropagation` 弹窗壳**未走共享 `src/shared/ui/Modal.jsx`（V70 已抽 `Modal` + `ModalHeader`，逻辑零改动、纯壳 + 头部）。这 15 处是 V70 登记表所记"蒙版规则已共享，Modal UI 仍重复"的残留——每处各自抄了一份 `div.modalLayer onMouseDown=onClose` + `section onMouseDown=stopPropagation`，改一处会漏另一处。

本单**只扩散其中 7 处位于 `src/features/**` 的壳**（见 §1.2 映射表）。理由见 §1.5：另 8 处位于 `main.jsx`(6) + `outfit-workflow.jsx`(2)，被 `modal-shell-check.mjs` 的 `main.jsx=0 / outfit-workflow.jsx=0` `<Modal>` 计数**写死钉死**（该门禁专为守护裁剪/回贴弹窗不被搬回而设），迁移它们必须改造门禁 → 单列 🔴 高风险项 **V100（主壳/outfit 壳 + 门禁改造）**。

## 1. 改动要求

### 1.1 策略：只换壳，保留原 `<header>` 作 children（DOM 逐字节等价，零视觉变化）

共享 `Modal` 的渲染为：

```jsx
<div className={layerClassName} onMouseDown={onClose}>
  <section className={panelClassName} onMouseDown={(event) => event.stopPropagation()}>
    {children}
  </section>
</div>
```

→ 把每处 bespoke 壳的 `div.modalLayer onMouseDown={X}` + `section SOMEPANEL onMouseDown={stopPropagation}` **整体替换为** `<Modal layerClassName="modalLayer ..." panelClassName="SOMEPANEL" onClose={X}>`，原 `<header>` 与 `<body>`/`<footer>` 等 children **原样留在 `<Modal>` 内部**。

- **等价于**：DOM 输出（layer div 的 class + `onMouseDown=onClose`；section 的 class + `onMouseDown=stopPropagation`；children 层级）与改动前**逐字节一致**。
- **不使用 `ModalHeader`**（V70 的头部组件）：`ModalHeader` 把关闭钮 `X` 硬编码为 `size={16}` 且只渲染 `h2`+`span`。本单 4 处现用 `X size={18}`（PromptEditorModal / OutfitSettingsModal 目录弹窗 / SettingsView / PromptAssistantView），改用 `ModalHeader` 会改视觉（18→16）。故**头部原样保留**，仅换外层壳——纯结构重构、零视觉变化（与 `Modal.jsx` 自身注释"不加原来没有的行为"同口径）。
- **不迁移 main.jsx / outfit-workflow.jsx 的壳**（§1.5 边界）。

### 1.2 🔴 最高约束：类名与 DOM 结构零改动（壳层）

- **必须原样保留**：所有 `panelClassName`（`settingsModal` / `saveDirectoryModal` / `promptEditorModal` / `previewModal` / `promptAssistantModal`）、`layerClassName` 附加类（`promptEditorLayer` / `promptLayer`）、`<header>` 内的 `h2` / `span` / 关闭 `<Button iconOnly>` 的 `X` 尺寸与 `aria-label`、以及 children 的任何结构层级与文案。
- 共享 `Modal` 已自带 `onMouseDown` 行为（layer→`onClose`、section→`stopPropagation`），**不得**在 children 里再加/改这些 handler。
- 本单**不触碰** `scripts/verify/` 任何探针脚本（7 处目标壳不在门禁选择器覆盖内；门禁 `modal-shell-check` 只数 main/outfit/quickCrop/outfitPanel/localEdit 五个文件）。

### 1.4 逐文件动作

- **补 import**（不带 `.jsx` 后缀，仓内惯例）：

## 2. 验收

### 2.1 静态

- 5 个目标文件各 `git grep -n "modalLayer" -- <file>` → **0 命中**（已换成 `<Modal layerClassName="modalLayer ...">`）；各文件 `git grep -n "<Modal" -- <file>` → 对应壳数命中（#1/#2 文件 2，#3 文件 1，#4 文件 1，#5 文件 1，#6/#7 文件 2）。
- 面板类（`settingsModal` / `saveDirectoryModal` / `promptEditorModal` / `previewModal` / `promptAssistantModal`）仍仅在原文件 + CSS + README 出现，class 名未变。
- `scripts/verify/` 下所有探针脚本**零改动**（grep 核对）。
- `git grep -c "Modal" -- src` 各目标文件计数变化符合预期（仅因 import + `<Modal` 替代 `div.modalLayer`/`section` 文本，无净增逻辑）。

### 2.2 行为 / 视觉（执行者自测 + 统筹探针）

- 各弹窗打开/关闭行为不变：点遮罩关闭、点面板内部不关闭、关闭钮可用；设置/提示词助手/结果预览/编辑提示词弹窗显隐正常。
- **零视觉变化**（壳类名、header 结构、`X` 尺寸、间距、文案与改动前一致）。

### 2.3 门禁（路由纪律①：非里程碑、不触 run-all/sandbox/package.json）

- `--fast` **32/32**
- `npx vite build` EXIT=0
- `npx eslint .` → **0 errors**；warning 仅允许基线 1 条（`server/routes/outfit.routes.js:407`，别动）
- `node scripts/verify/modal-shell-check.mjs`：源码级断言应**全过**（5 个受计数文件未动、共享壳文件存在、4 个承载文件 import 不变）；浏览器部分若环境无 tabbit 则跳过并记为挂起（与 V98 四主题走查同口径），**不阻塞归档**。

### 2.4 基线

- **预授权 `--update`**：`shared-ui-duplication` / `frontend-duplication`（AGENTS.md：抽取/复用共享组件后**必须**刷新，V82/V90/V91/V98 同例）。
