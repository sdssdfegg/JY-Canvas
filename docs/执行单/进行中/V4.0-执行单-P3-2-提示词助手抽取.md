## 2. 阶段 B —— 抽取方案

**三件套文件清单**：

- `src/features/prompt/PromptAssistantView.jsx`：主画板提示词助手弹窗/面板 JSX + 交互（搜索、分类筛选、拖拽排序、编辑预设）。
- `src/features/prompt/prompt-assistant-state.js`：纯逻辑/hook（零 JSX）——承接下方“搬”列状态 + 预设持久化 effect（`writeJsonStorage`）。
- `src/features/prompt/README.md`：职责/入口/状态归属/常见改法/后端配合。

**main.jsx 接线点**：

- 删除 5266 起 `{isPromptAssistantOpen && (…)}` 整块，改为 `<PromptAssistantView presets={promptPresets} categories={promptCategories} onPresetsChange={setPromptPresets} onCategoriesChange={setPromptCategories} isOpen={isPromptAssistantOpen} onClose={() => setIsPromptAssistantOpen(false)} … />`。
- `promptPresets`/`promptCategories` 仍由 App() 持有（主画板+批量页**共享数据**），作为 props 下发；持久化 effect 随数据走，搬进 `prompt-assistant-state.js`（或共享 `prompt-state`）。

**状态迁移映射表（逐项）**：

| 状态 / 代码 | 行 | 处置 | 理由 |
| --- | --- | --- | --- |
| `promptPresets` / `promptCategories` | 655–656 | **留共享**（App() 或 `shared/prompt-state.js`） | 主画板+批量页共用数据，不许复制 |
