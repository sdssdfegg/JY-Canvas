## 2. 负责人裁决（执行 AI 不得自行改判）

1. **弹窗宽度**：由 520px 提升到 **720–820px 区间**（建议 `min(760px, 100%)`），并补 `max-height: calc(100vh - 48px)` + `overflow-y: auto`。**禁止改 `.detailPresetModal`**：须为弹窗新增**一个专属布局类**（建议 `.detailSectionsModal`），只含 `width` / `max-height` / `overflow` 等布局属性，不含颜色、不含 `Button` 字样（`module-template-check` B5 禁 `xxxButton` 类名、B6 禁 hex）。`panelClassName` 换成专属类；执行 AI 须先核 `styles.css:2591-2660` 的共享规则，确认 `ModalHeader` 版式不破。**本单明文授权 `styles.css` 仅新增这一个布局类及其作用域内规则，既有选择器一律不动。**
2. **「非必选」标签**：走 `ModalHeader` 的 `action` 槽（已支持），文案「非必选」，复用现有 pill 类（`.referenceCountPill` / `.eventPill` / `.taskBadge` 三选一，取视觉最接近者），**零新增 CSS 类**。不得改 `src/shared/ui/**`。
3. **两列分组**：在 `.detailSectionsModal .promptPresetGrid` 作用域内设 `display:grid; grid-template-columns:repeat(2,minmax(0,1fr))` 或等价布局；**不得改全局 `.promptPresetGrid`**（`styles.css:2940`），否则外溢到预设弹窗与其它板块。窄屏须可退回单列（响应式 `min-width` 或容器查询任选，不新增类）。
4. **排序交互**：**保留 HTML5 拖拽**（V214 验收硬项），**同时**为已选每条补 `ChevronUp` / `ChevronDown` 按钮复用现有 `onMove`，图标类复用 `.promptChipIcon`；标题右侧补「N 项」计数（可复用 `<em>` 范式）。↑↓ 只是拖拽的等价补充，**不得改变 `selectedSections` 数组顺序语义与 `order` 派生规则**。
5. **自定义区**：placeholder 改「例如：产品环保材质说明」，按钮文案「添加」，下方补说明小字「自定义板块也可以参与排序和后续 AI 策划。」（复用现有说明文字类或语义标签 + 既有类）。`createCustomSection` / `moduleId:"custom"` / 删除 / 清空逻辑**一律不动**。
6. **底部按钮**：保留「取消 / 确定 / 清空」三个动作（V214 §5.2 验收要求「取消关闭弹窗」「未选可继续生成」），排版按示意稿做**左弱化 / 右主操作**两段式；文案可对齐为「清空选择」。示意稿的「复制当前选择」语义与「关闭并生效」不符，**本单不实现**（U-001 待 Owner 确认，不得擅自加）。主按钮仍只有一个（`ui-button--primary`）。
7. **分组删除位置与形态**：在 `.detailGroupActions`（`DetailView.jsx:396-423`）加一个共享 `<Button tone="danger" size="sm">` + `Trash2` + `window.confirm` 二次确认（对齐 outfit 惯例），**CSS 零改动**（现有 flex 容器可容纳）。若执行 AI 选择把删除放进 tab 内，须额外改 `styles.css:2051` 一处并在回报里说明，且**不得改 `DetailView.jsx:363` / `:390` 的文本**（`detail-stylepack-off-check` C7/C8 正则锚点）。
8. **删除语义（保护用户资产）**：`deleteDetailGroup(groupId)` 只从 `detailGroups` 过滤该组、主动清 `detailInfoSelection`、`addEvent` 记一条日志；**不删 `history.json`、不删 `data/history-images` 磁盘图、不动全局 `results`、不动预设**。删除后 `activeDetailGroupId` 由既有 effect（`:214-223`）复位；须实测删当前 active 组、删中间组、删到空三种情形。**生成中（`status === generating`）的组禁止删除**（按钮 disabled 或 confirm 内明确提示），避免产生「有图无组」孤儿结果。
9. **不改业务逻辑**：本单是 **UI 与交互增量**，不改 `detail-sections.js` 常量与序列化、不改 `detail-state.js` 的 payload 条件注入、不改 `main.jsx` 挂载、不改任何服务端策划与分屏逻辑。V214 的「空选逐字节一致」「板块真进 Agent」必须原样保持。
