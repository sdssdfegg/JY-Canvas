## 1. 需求（统筹复核发现，2026-10-17）

V78 统筹复核独立复跑全量门禁时发现：`modal-shell-check` 判红 3 条断言（全量 run-all 48/50 的两笔失败之一）。根因：

- V70（commit `bdbaf6a`）把 `ModalHeader` 关闭钮从裸 `<button className="iconButton">` 改为共享组件 `<Button size="md" iconOnly>`——后者渲染的 class 是 `ui-button ui-button--md ui-button--icon`，**不再有 `iconButton`**；
- 探针（`scripts/verify/modal-shell-page.jsx`）仍按 `button.iconButton` 找关闭钮，自 V70 起全部落空；
- 该 check **不在 `--fast` 子集**（FAST_ORDER 无它），V70 以来各单只跑 `--fast`，无人全量复跑，锈蚀未爆。

**产品行为完好**（取消/应用/重开/遮罩关闭/Esc 不关/卸载清理断言全过），坏的是探针选择器。本单修复探针，恢复 `npm run check` 全绿口径。

## 3. 改动要求

### 3.1 探针选择器修复（5 处）

`scripts/verify/modal-shell-page.jsx` 的 5 处 `button.iconButton` 全部改为 `button.ui-button--icon`（76/77/103/186/254 行，按派发日实测行号）。**语义不变**：仍找 header 里的图标关闭钮、仍验其 X 图标 svg 与 aria-label 有无。

### 3.2 断言名措辞（1 处）

`scripts/verify/modal-shell-check.mjs:195` 断言名 `浏览器：关闭按钮是 iconButton（带 X 图标）` → `浏览器：关闭按钮是 ui-button--icon（带 X 图标）`。只改措辞，判定逻辑不动。

### 3.3 修复后必须仍成立的三条真空过风险点

- `modal-shell-page.jsx:103`（不传 closeLabel 不渲染 aria-label）：修复后按钮可找到，须验"按钮存在且 aria-label 属性缺失"仍使断言为 true；
- `modal-shell-check.mjs` 里 `ariaLabelOmittedWhenNotProvided` 判据同上，一并真过；
- 快捷/批量两入口 `closeButtonPresent` 修复后须为 true（且不得靠放宽选择器凑过——只许精确匹配关闭钮）。
