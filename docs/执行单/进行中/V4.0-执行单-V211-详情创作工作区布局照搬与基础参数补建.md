## 2. 五处架构裁决（统筹默认口径，Owner 可改）

1. **分段卡片照搬的是「布局与交互外观」，不是「数据语义」**：旧模块是「可编辑 textarea + enabled 复选」，新工作区宪法级要求是「展示的提示词 == 实际生成提示词」「用户确认后冻结」「模式 C 原文只读」。故**保留 `frozenPrompts` 字节冻结链**：卡片可改，但改后必须显式重新编译/冻结才生效，生成端只读冻结值，后台零改写。若直接照搬旧语义会破坏 V202/V209 成果与模式 C 红线。
2. **拼图预览自写工作区内面板**：旧版在 `main.jsx:1265` 是 App 级 Modal，而 `main.jsx` 禁改 ⇒ 不搬、不 import 旧模块，参考 `stitchDetailGroupBlob` 思路在 detail-studio 内自写 canvas 拼接与预览。
