## 2. 目标域与方案

**方案：逐字搬迁 + 引用方直改**（同 V5.0-008/009/010 先例，不留 re-export 壳）：

1. 新建 `src/features/outfit/handlers/outfit-task-retry.js`，export `useOutfitTaskRetry(ctx)`，`retryTask`/`rerunResultTask` 按原顺序逐字搬入；
2. 新建 `src/features/outfit/handlers/outfit-recolor-part.js`，export `useOutfitRecolorPart(ctx)`，`selectRecolorPart`/`selectRecolorUpperLayer` 按原顺序逐字搬入；
3. 两个新 hook 均为**纯函数工厂（内部无任何 React hook）**，返回函数每次 render 重建——与组件内 function 声明行为零差异（ctx 薄壳模式同 outfit-page-switch.js）；
4. 调用点：
   - 任务重试 hook：置于 `useOutfitBatchExecution` 块之后（`startBatchRef.current = startBatch;` 之后）——其 ctx 依赖的 `runSingleTask/beginGenerationRun/endGenerationRun` 来自该 hook，`addEvent` 来自 settings-intent(738)，`running/canAppendWhileRunning/tasksRef/setTasks` 均为 state/ref；
   - 改色 hook：置于 `useOutfitSettingsIntent` 解构之后（`addEvent` 可得）——JSX 唯一消费，无其他时序约束；
5. 组件侧 import 摘除（逐个核对：迁移后该标识符在组件内消费数必须为 0）：
   - `outfit-task.js` import 块摘 5 个：`taskRuntimeStageLabel`、`summarizeGenerationError`、`revokeResultImageRuntimeCache`、`canRerunTask`、`buildRerunReplacementTask`（保留 `readTaskHistory`/`normalizeRandomBackgroundFocus`）；
   - `generation-errors.js` 整行摘（仅 `sanitizeErrorText` 一个标识符）；
   - `outfit-top.js` import 摘 5 个 recolor 标识符：`RECOLOR_PART_WORDS`、`replaceRecolorPartWords`、`replaceRecolorUpperLayerWords`、`replaceUpperLayerWordsWithPart`、`RECOLOR_PART_OPTIONS`（保留 9 个，含 `normalizeRecolorPart`/`normalizeRecolorUpperLayer`——派生值 396–397 留组件）；
   - `outfit-intent.js` 整行摘（仅 `UPPER_LAYER_OPTIONS` 一个标识符）。
