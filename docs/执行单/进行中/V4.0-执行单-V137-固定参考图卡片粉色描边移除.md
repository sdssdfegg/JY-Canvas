# V4.0 执行单 V137 — 移除固定参考图卡片的粉色描边

## 背景与诉求
用户（2026-10-23）反馈：批量生成/换装 composer 里，点了 🔒 固定某张参考图后，该卡片出现粉色描边+光晕（`#ec6f9e` 硬编码），与整体框色不一致。要求：取消红框，与其他卡片边框颜色一致。

## 定位
- 样式来源：`src/outfit-workflow.css` `.outfitWorkflowEmbedded .thumbCard.fixed { border-color:#ec6f9e; box-shadow: …rgba(236,111,158,.18) }`。
- 触发链：`outfit-panels.jsx` thumbCard className `fixedId === item.id ? "fixed" : ""`（点击锁按钮 onSetFixed 置位）。
- 全库 grep `ec6f9e`：唯一硬编码处即上条 CSS；其余出现均为「柔粉(jade)」子主题的正规 accent 定义（tokens.css / settings-state.js / outfit-top.js），不属本单范围。

## 改动
1. `src/outfit-workflow.css`：删除 `.thumbCard.fixed` 粉色描边规则（-4 行），留注释说明状态改由锁按钮表达。
2. `src/features/outfit/outfit-panels.jsx`：锁按钮加 `className={fixedId === item.id ? "active" : ""}`，复用既有 `.thumbActions button.active`（accent 底色小按钮），保留"哪张被固定"的可发现性。

## 设计取舍（自行裁决留档）
- 若仅删描边不补按钮高亮，用户将无从得知当前固定的是哪张图（原描边是唯一指示）。按钮高亮是既有组件语言（局部回贴剪刀按钮同款），不新造样式。
- 卡片 `fixed` className 保留（JSX 判定仍在），便于未来需要时恢复样式挂钩。

## 门禁
- ESLint（outfit-panels.jsx）：0。
- size-ratchet：无回归；体量净下降（outfit-workflow.css -4 行）。
- 视觉验证：待用户在 v4.0.16 打包版确认。
