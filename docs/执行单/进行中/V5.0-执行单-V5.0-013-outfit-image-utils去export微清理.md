## 1. 背景与结论

NEXT.md 候选① 评估结论：**`outfit-image-utils.js` 不建议按域拆分**。理由：
- 它是纯函数工具桶（37 个 named export、无状态、无渲染热点），内部已按 5 块逻辑分组（常量/resize、文件拖拽 IO、图片加载、canvas 导出、图像流水线），可读性无问题。
- 开发宪法禁止 re-export 壳 → 拆分必须改 16 个引用方的 import 路径，为纯排版收益动 16 文件、零行为改善 = 负 ROI。

本单改为做该评估顺带发现的**低风险真清理**：5 个“仅本文件内部使用”的助手被不必要地 `export`，缩公开 API 面。
