## 4. 留档（统筹写入）

- **产品口径最终版（改色页头部）**：`更换部位 + chips ｜ 上装层级 + chips` 一条紧凑行；提示词标题（通用改色提示词）回到输入框上方，与全站提示词标题同字号同层级；**没有**"恢复默认模板"入口——用户手写提示词受保护（无部位词不联动 + 可见提示），但要不要恢复模板由用户自己编辑，不再提供一键按钮。
- **V117→V119→V120 演进**：V117 加按钮（兜底入口）→ V119 挪位置（参考图）→ **V120 删按钮 + 标题归位（用户实测后拍板）**。后续引用改色页头部布局以本单为准。
- **教训**：给"兜底"配 UI 入口前先确认用户要不要——V117 的按钮是统筹的推断，V120 证明用户不需要；兜底提示文案里**不要引用可能被删的 UI 元素**。
