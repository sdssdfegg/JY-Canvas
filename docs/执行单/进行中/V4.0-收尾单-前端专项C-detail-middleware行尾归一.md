## 2. 目标

仅做一件事：把 `server/detail-middleware.js` 磁盘内容由 CRLF 归一为 LF，使其与 `.gitattributes` 声明一致。

**不做的**：不改任何一行代码逻辑、不重命名、不格式化缩进、不动 `detail-ai.js`、不动 `src/**`、不动其他 CRLF 文件（那 52 个 index-CRLF 文件已裁决**不动**，理由见 README）。

## 3. 改动步骤

1. 重测锚点：`awk 'END{print NR}' server/detail-middleware.js`、`grep -c $'\r' server/detail-middleware.js`（或等价 node 统计）。
2. **第 1 步（安全闸门）**：确认无跨行模板字符串。方法：逐行统计未转义反引号个数，检测跨越 ≥1 个换行的模板块；**结果必须为 0**，否则**停手回报**，不得转换。
3. 转换：用 node 读取 → 将 `\r\n` 全部替换为 `\n` → 写回（**不要用 `git checkout` / 编辑器自动转换**以免夹带其他改动）。
4. 自检：`git diff` 应只有行尾变化（`git diff --stat` 的增删数应约等于文件行数×2，且 `git diff --ignore-cr-at-eol` **必须为空**——这是"纯行尾改动"的硬判据）。

## 6. 删除与 `.lock` 纪律（硬性·照抄执行）

**客户端三层劫持实测结论**：bash 层 `BASH_ENV` 注入 `rm()` 函数、node 层 `NODE_OPTIONS` patch `fs.*Sync`。因此**裸 `rm`、裸 `fs.rmSync` 都会走 genie-trash 进回收站**——"禁用 safe-delete 工具"是空话，因为中招的是动作本身。

允许姿势（四选一）：

1. bash：`/usr/bin/rm -rf <path>`（**必须绝对路径**，不能用别名 `rm`）
2. node 脚本：`spawnSync("/usr/bin/rm", ["-rf", p])`
3. 命令行前缀 `CODEBUDDY_SAFE_DELETE_ENABLED=0`（官方 kill switch）
4. PowerShell `Remove-Item -Recurse -Force`

**禁止**：裸 `rm` / `rmdir` / `unlink` / 裸 `fs.rmSync` / 任何"先暂存再删"封装。
收尾清理自建临时文件（本单若有），回报附删除姿势与 `.lock` 增量（应为 0）。
