## 1. 改动要求

### 1.1 任务存储层（新增 `server/ai-tryon/`，目录终判由执行方按依赖方向定）

- `task-store.js`：`data/ai-tryon/tasks/<task_id>.json` + `index.json`；**临时文件+原子替换**；单写入器串行化索引变更（总纲风险表「JSON 并发写入」行）；
- 🔴 **零依赖叶子纪律**：启动恢复扫描会 import 它——只准依赖 node 内置 + `server/core/app-paths.js`，**禁入特性模块群**（V121-R2 TDZ 教训：启动链路模块被 rollup 打包后初始化期 TDZ 会白屏，且 build EXIT=0 抓不到）；
- 任务记录字段 = contracts/tryon-task.md §1 全集（P1 不实现的字段可空但结构在位）。

### 1.2 状态机最小版

- 实现子集：`CREATED → VALIDATING → READY_TO_GENERATE → GENERATING → EVALUATING → SUCCEEDED/FAILED/CANCELLED/NEEDS_REVIEW`（ANALYZING/POSTPROCESSING/REPAIR_PENDING/RETRY_WAIT 随 P3/P4 补齐，契约已留位）；
- 铁律落位：先持久化后调用；终态不静默覆盖；重启扫描非终态 → 恢复或标 NEEDS_REVIEW，**不盲目重新生图**；预算/重试检查发生在调用之前。

### 1.3 Prompt 模板挂载

- 服务端权威组装（固定规则层 + 单次任务指令层；档案层/模特约束层留接口，P2/P3 填）；
- `prompt_template_version` + 内容哈希；每任务冻结并写入任务与日志；
- 双分支句按前置条件②固化。

### 1.4 日志字段扩展

- 按 contracts/log-fields.md：只增不删；旧消费者零影响；禁 KEY；记引用不复制。

### 1.5 路由与恢复

- `/api/generate-outfit` 内嵌任务状态写入（请求入口建/更新任务，响应后落 attempt + 结果资产引用）；**不新增路由、不改并发槽**；
- 启动恢复扫描（`server/index.js` 启动链路，零依赖 import）；
- UI 最小可见：现有任务展示处带 task_id/status（不建新面板）。

### 1.6 测试

- 单元：状态转移合法性、预算判定、重试分类、Prompt 编译与版本快照、日志字段；
- 契约：任务存储读写/原子性/损坏尾部容忍；
- 集成：上传→建任务→生成→归档→取消→重启恢复→失败重试；
- 门禁：--fast 全绿 + eslint 0 errors + build EXIT=0；**发版前 public 模式首启动冒烟**（V121-R2 铁律）。
