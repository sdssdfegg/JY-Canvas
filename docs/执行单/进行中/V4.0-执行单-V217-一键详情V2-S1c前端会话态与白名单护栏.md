## 4. 冻结契约（S0 §5.1 / §5.3 数据边界四条红线）

```
planningContext = {
  planning,                 // 服务端响应顶层字段，可为 null
  screens: [{ index, role, visualSpecDigest }],  // 后续阶段用；S1-c 只需能容纳
  instruction, history      // 后续阶段用；S1-c 不实现多轮
}
```

1. **不进 `detailSettings`** ⇒ 否则 `saveDetailPreset`（`detail-group.js:233-245`）落 `DETAIL_PRESETS_KEY`。
2. **不挂 `group`** ⇒ 否则 `detail-state.js:210-212` → `sanitizeDetailGroupsForStorage` 落 `DETAIL_GROUPS_KEY`。
3. `apiKey` / `baseUrl` 只随请求走内存，不写任何持久化、日志、种子。
4. `seed/manifest.json` 零改动；发布包不含生图信息记录；前端零 KEY 记录。

白名单护栏是**防御性**的：即使未来有人误把 V2 中间态挂到 `group` 或塞进 `settings`，也会被两个入口剥离，不会扩散到预设 / 分组 / 发布种子。**禁止 import B 域 `director-visual.js` 的同名 `planningContext` 变量。**
