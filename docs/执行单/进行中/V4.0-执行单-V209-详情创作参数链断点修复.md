## 1. 四处断点的当前代码证据（本单发单前实证，非引用旧报告）

### 1.1 P0 · A/B 冻结后批量生成必失败（主流程硬阻断）

- 写入：`server/features/detail-studio/planning/compile-screen.js:32` → `frozenPrompts[screen.id] = prompt`，键为 **`screen_1` / `screen_2`**。
- 读取：`server/features/detail-studio/generation/routes.js:70` → `frozenMap[i]`，键为**数字索引 `0/1`**；回退 `screen.frozenPrompt || screen.raw` 在 `ScreenSpec` 中无对应字段。
- 复现（发单前实跑）：构造 2 个 `screen_N` + 对应 `frozenPrompts` 的项目，补合法渠道 `silent-tt26-line-01` 后动态 import `buildBatchSpec(project, {})` ⇒ **抛错「没有可生成的屏（请先冻结提示词 / 完成分屏规划）」**。
- 门禁缺口：`scripts/verify/frozen-prompt-parity-check.mjs:74-80` 只断言 `plan.frozenPrompts.screen_1 === a1.prompt`（compile 端自洽），**从未验 generation 端读取**，所以一路未抓到。

### 1.2 P0 · 参考图未进出图请求

`generation/routes.js:32` 组装 `referenceImagePaths`、`:56/:75` 放进 `spec.screens[]` → `orchestrator.js:96-116` `submitBatch` 调 `buildTaskRecord` **未传该字段** → `task-model.js:117` 形参**无此字段** → `orchestrator.js:192` `referenceImagePaths: current.referenceImagePaths || []` 恒空 → `local-images-generator.js:33` 循环空 ⇒ `/api/images` 请求不带任何参考图。

### 1.3 P1 · 用户选的推理模型不生效

`src/api/detail-studio.js:112/117` 已支持 `{ apiKey, textModel }`、服务端 `modelName(input, SPEC)` 已接；但 `use-detail-studio-state.js:360/386` 的 `analyzeProject` / `directorProject` 只传 `{ apiKey }` ⇒ 前端模型下拉的值到不了服务端。

### 1.4 P1 · 行业宣传边界未进质检

`prompts/detail-studio/quality/qc-prompt.js:40/:64-66` 已定义 `industryStrategy` 入参并拼 `promoBoundaries`；但 `server/features/detail-studio/planning/qc-review.js:99 runQualityCheck({ project, apiKey, textModel, signal })` 未取、未传 ⇒ 行业合规边界只进了导演提示词，没进独立质检。V206 报告 `:277` 判「部分接入」，V207 报告确认为已知缺陷。
