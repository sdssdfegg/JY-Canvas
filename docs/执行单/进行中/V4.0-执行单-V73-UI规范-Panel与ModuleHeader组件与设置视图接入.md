## 3. 改动要求

### 3.1 新建组件（`src/shared/ui/`，样式追加进 `ui.css`，LF 行尾）

1. **`Panel.jsx`**：`<Panel padding="md|lg" tone="default|strong" className>` → `<div className="ui-panel ui-panel--{tone}">`；`background: var(--panel)`、`border: 1px solid var(--border)`、`border-radius: var(--radius-lg)`、padding 走 `--space-4`(md)/`--space-6`(lg)、`display:grid; gap: var(--space-4)`。替代 `.skinBlock`/`.debugBlock` 一类卡片容器。
2. **`ModuleHeader.jsx`**：`<ModuleHeader icon title subtitle action>` → `<div className="ui-module-header">`：左侧 `icon`（lucide 元素，可选）+ `title`（14px/500）+ `subtitle`（12px muted，可选）；右侧 `action` 节点（可选，右对齐）；底部 1px 分隔线可选（`divider` prop，默认 true）。替代手写 `<span><Icon/> 标题</span>`。

函数体 <50 行（size-ratchet）；原生属性透传规则同 V70 `Button`。
