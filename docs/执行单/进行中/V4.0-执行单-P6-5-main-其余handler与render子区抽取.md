## 6. 回收站 `.lock` 清理纪律（硬性）
- **根因**：历史优化/沙盒清理把 `*.lock` 目录 `safe-delete` 进回收站长期堆积（实测 C: 回收站 SID `S-1-5-21-...-1001` 已 **12273** 个 `.lock` 文件夹）。本批执行单**严禁**再制造或 safe-delete 这类目录。
- **执行结束前必做**：直接删除工作区与临时目录残留的 `*.lock` 目录（PowerShell，先 `-WhatIf` 预览、确认无业务文件后再去 `-WhatIf` 执行）：
  `Get-ChildItem -Path <本单工作根> -Recurse -Directory -Filter '*.lock' | Remove-Item -Recurse -Force`
  须覆盖 `<工作根>`、`tmp/`、`node_modules/`、沙盒目录。
- **禁止**：任何 `mv ... 回收站` / `safe-delete` / 改名进回收站的 `.lock` 清理方式——`.lock` 属可丢弃锁文件，直接 `Remove-Item` 即可，无需进回收站。
- **回报附证**：度量 §5 之外，附 `Get-ChildItem -Recurse -Directory -Filter '*.lock' | Measure-Object` 的工作区计数（应为 0）。
