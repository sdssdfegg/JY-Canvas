## 3. Tool 契约（照抄 V207-02 §3.1，不得自行扩字段）

```ts
interface Tool {
  id: string;
  description: string;            // 供 Agent 选择
  permissions: string[];
  idempotent: boolean;            // 决定是否走 idempotencyKey
  confirmRequired: boolean;       // 是否需用户确认
  sideEffectScope: 'project' | 'screen' | 'global';
  run(args: ToolArgs, ctx: RunCtx): Promise<ToolResult>;
}
// ToolCall{ tool, args, confirmed? } → ToolResult{ ok, data, sideEffects[] }
async function dispatchTool(call: ToolCall, ctx: RunCtx): Promise<ToolResult>;
```

- **本层负责**：把影响世界的确定性操作封装为标准化调用、统一入参校验与元数据、拒绝非法调用。
- **本层不负责**：意图理解、领域知识、提示词拼装、模型调用、任务状态跃迁（分别属于 Agent / Skill / Model Adapter / Orchestration）。
- **由模型决定**（P5 起）：选哪个 Tool、传什么参数。**必须由代码控制**：Tool 实现本身、权限边界、幂等键、并发闸门、`confirmRequired` 拦截。
