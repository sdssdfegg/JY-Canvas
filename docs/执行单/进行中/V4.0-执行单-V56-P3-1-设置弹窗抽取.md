## 2. 阶段 B —— 抽取方案

**三件套文件清单**：

- `src/features/settings/SettingsView.jsx`：弹窗 JSX + 交互（API Key 输入/显隐、存储后端切换、保存目录选择、连接测试按钮）。
- `src/features/settings/settings-state.js`：纯逻辑/hook（零 JSX）——承接下方“搬”列状态 + 连接测试/存储读取的副作用 effect。
- `src/features/settings/README.md`：职责/入口/状态归属/常见改法/后端配合（范本 `src/api/README.md`）。

**main.jsx 接线点**：

- 删除 5125 起 `{isSettingsOpen && (…)}` 整块（约 5125–5265）。
- 改为 `<SettingsView settings={settings} config={config} updateSetting={updateSetting} saveDirectory={saveDirectory} setSaveDirectory={setSaveDirectory} directoryDraft={directoryDraft} setDirectoryDraft={setDirectoryDraft} isPickingDirectory={isPickingDirectory} setIsPickingDirectory={setIsPickingDirectory} isSettingsOpen={isSettingsOpen} onClose={() => setIsSettingsOpen(false)} />`，保留 `isSettingsOpen` 由 nav/header 控制不变。
- `settings`/`config` 仍由 App() 持有（全局 KEY 源），作为 props 下发——**不得把 settings 搬进视图**，否则 P3-6 快捷生成读不到 KEY。

**状态迁移映射表（逐项，不留“等等”）**：

| useState | 行 | 处置 | 理由 |
| --- | --- | --- | --- |
| `config` | 653 | **留 App()** | 全局 `hasServerKey`/`models`/`defaultBaseUrl`，所有视图读 |
| `settings` | 654 | **留 App()** | 含 `apiKey`/`baseUrl`，全局 KEY 源，P3-6 等共享 |
| `saveDirectory`/`directoryDraft`/`isPickingDirectory` | 685–687 | **留 App()（共享）** | 设置里选、快捷生成里用，跨视图共享 |
