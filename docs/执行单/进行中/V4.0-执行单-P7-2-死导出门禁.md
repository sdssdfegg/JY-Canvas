## 2. 做法
1. 新建 `scripts/verify/dead-export-check.mjs`（约 120 行）：
   - 收集 `src/**/*.{js,jsx}` 的**具名导出**（`export function` / `export const` / `export { x }` / `export default` 按文件级处理）。
   - 统计每个导出名在**其他文件**中的引用次数：匹配 `import ... from`、动态 `import()`、以及 `from "..."` 的解构名。
   - 引用次数为 0 → 死导出候选。
   - **排除/谨慎项（必须显式处理并写注释）**：
     - 入口文件与 `index` 再导出桶；
     - 被字符串/动态方式引用（如 `window.__x`、`mod[name]`）→ 命中即视为已引用，避免误判；
     - `export default` 的组件若被 `React.lazy(() => import(...))` 引用需算已引用。
2. **基线棘轮**：候选清单落 `baselines/dead-export.json`（`{generatedAt, reason, items:[{file,name}]}`）。
   - 判红：① 出现**不在基线内**的新死导出；② 基线项已消失但基线未更新（`stale`）→ 红。
3. `--update` 重写基线（带 `--reason`）；`--json` 供 run-all。
4. 注册进 `scripts/verify/run-all.mjs` + `--fast` 子集。

## 4. 负向对照（双向）

- 红②：给某个基线里的死导出**加上一处真实引用**（或删掉该导出）但不 `--update` → `stale` 红；`--update` 后 → 绿。
