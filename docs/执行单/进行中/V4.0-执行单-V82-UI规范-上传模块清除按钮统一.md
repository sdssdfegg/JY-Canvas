## 1. 需求（用户原话转译）

「这个清除按钮应该是每个上传图片的模块右上角都有一个，目前除了换装的图1和图2，其他的上传模块都没有；然后把垃圾桶图标去掉，把清除2字居中于按钮中间——不然垃圾桶图标和文字都超出了按钮，这个设计不是很不合理吗。」（用户附截图：换装清除钮内 Trash2 图标与「清除」文字堆叠溢出。）

第二轮修订（用户附截图：换装「下装/连衣裙/鞋子」选项钮）：「按钮的颜色不用做成红色那么突出，就跟截图的这个选项一个颜色就好了；然后按钮缩短一点，跟这个鞋子的按钮大小就可以了。」

交付定义：**所有上传图片模块**右上角都有统一形态的「清除」钮；钮内**只有居中的「清除」文字，无图标**；**中性灰配色（不抢眼）**、**紧凑尺寸（与截图中「鞋子」选项钮同阶）**。
