## 2. 做法
1. 新建 `scripts/verify/size-ratchet-check.mjs`（约 120 行）：
   - 扫 `src/**/*.{js,jsx}`：记录**每个文件**行数；记录**每个函数体**行数（起点匹配 `^(async )?function `、`^  (async )?function `、`^const X = (`、`^  const X = (`，终点取下一个同级起点或文件末）。
   - 落 `baselines/size-ratchet.json`：`{generatedAt, reason, files:{path:lines}, functions:{"path:startLine":lines}}`。
2. **棘轮语义（核心）**：
   - 判红：任一文件/函数当前行数 **>** 其基线值 → 红（提示"体量上升，请确认是否必要，或跑 --update 并写理由"）。
   - 下降不判红（鼓励）。
   - `stale`：基线里记的文件被删/函数被移走 → 判红，逼 `--update`。
3. **绝对上限（只报告不拦）**：单函数 >600 行、单文件 >2500 行 → 记入 `overBudget` 清单，脚本仍 `ok=true`，但在输出里醒目标注，供统筹决定是否另开单（当前 `outfit-page-actions.js:176` ~537 接近上限）。
4. `--update`（带 `--reason`）/`--json`。注册进 `run-all.mjs` + `--fast`。

- 绿：现状 == 基线 → `ok=true`。

- 红②：把某函数搬走（基线项消失）但不 `--update` → `stale` 红；`--update` → 绿。
- 红证输出贴回报。
