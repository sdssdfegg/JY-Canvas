## 2. 阶段 B —— 抽取方案

**三件套文件清单**：

- `src/features/quickgen/QuickGenView.jsx`：快捷生成 image 模式主视图 JSX + 交互（上传、生成、结果画廊、选择器、画廊缩放、编辑器挂载、预览）。
- `src/features/quickgen/quickgen-state.js`：纯逻辑/hook（零 JSX）——承接下方“搬”列状态 + 生成/画廊副作用 effect。

- 删除快捷生成 image 模式主内容块（派发日 grep 精确边界，约 3368/3422 子区 + 3495 image-editor 分支之前的 image 主内容 + 结果画廊区，至 4356 reference-remix 之前；**4575 video 子模式段留给 P3-3 已抽 VideoView，本单不重复抽**）。
