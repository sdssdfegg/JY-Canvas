### 1.2 统筹裁定（专业判断，写进单留档，可事后推翻）

1. **第四刀范围重裁定**：不做「深色底族」（§1.1 #7 已证其主体可收敛 0 处或属永久排除），改为 **`#061515` 5 处激活态文字色归顺既有 `--accent-on`**。理由：这是全仓剩余最大的真·可收敛族（5 处）、语义与既有令牌精确对应、同仓已有 3 组正确实现可对齐，且能修掉三套浅色主题的真实对比度缺陷；继续按色值大小切零散族只会「一直碎着发却看不到终点」。

3. **🔴 零新增令牌、严禁复用旁路口径**：不得为保住「零视觉变化」而新增一个四主题同值 `--ink-strong: #061515`（那会把对比度缺陷固化，且与 `--accent-on` 语义重复）；不得改动 `--accent-on` 的四主题值；不得把 5 处改成 `--accent-text`（该别名定义在 `outfit-workflow.css`，`styles.css` 应直接用 `--accent-on`，与 `:237/241` 一致）。**parity 必须仍 `baseKeys=23`**。
