## 2. 布局契约（整改后唯一口径）

```
detailStudioGrid
├─ 左列 (280–360px)
│   ├─ DetailStudioProjectPanel   项目列表 + 新建（现状）
│   └─ ModelChannelConfigPanel    3 个紧凑下拉（推理模型 / 图片模型 / 渠道）  ← 迁入
└─ 右列 (1fr)
    ├─ 主流程引导条                当前阶段 / 下一步 / 主按钮              ← 新增
    ├─ DetailStudioBasicsPanel     项目基础信息（保留）
    ├─ DetailStudioCapabilityPanel 单行状态条 + 折叠「开发者信息」          ← 瘦身
    └─ IntakeArea                  商品资料 / 参考图 / A·B·C 模式面板
        └─ ReferenceImageDropzone  点击 / 拖拽 / 粘贴 统一上传组件          ← 新增
```

- 视觉系统已关闭：**不产出任何设计规范、不新增主题/令牌**；沿用 `src/styles/tokens.css` 语义令牌与 `src/shared/ui/` 组件。
- 右列从上到下即客户操作顺序，不允许再插入调试型面板。
- 此布局为**契约**：阶段 3B / 4 新增面板须沿用，不得回退或重新堆成整屏卡片墙。
