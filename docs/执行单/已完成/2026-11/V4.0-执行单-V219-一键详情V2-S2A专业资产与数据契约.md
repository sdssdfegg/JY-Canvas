## 2. 已确认产品决策（9 条，逐条锁定，遵守方案 §1.3 五原则）

1. 商品图片是**唯一必选输入**，其它资料与设置均可选；
2. **count 由用户指定**，是硬约束（1–12，默认 8），AI 不增不减；
3. 无板块时 AI 自主规划指定屏数内的内容与视觉，**禁止回退固定标题轮转**；
4. 首屏海报是默认核心任务（hero），但不写死标题文字与正面居中构图；
5. 质检是**独立可选按钮**，用户可跳过直接生图；
6. 质检建议**不自动覆盖**用户已确认的提示词；
7. 不增加叙事偏好/视觉偏好等额外**必填**设置；
8. 不新增第二套 Provider / API Key / 模型网关 / 图片生成系统；
9. 不破坏旧版一键详情功能——旧链路输出逐字节一致处保持。

> 商品真实性高于营销创意、消费者利益高于参数罗列、整组叙事高于单屏美观、视觉服务内容、确定性问题不靠模型自觉——五原则来自方案 §1.3，资产内容必须体现。

### 4.3 评价维度（六项，逐项记录）
商品理解 / 营销策划 / 叙事逻辑 / 视觉创意 / 提示词质量 / 真实性。每项 1–5 分 + 严重错误标记；**商品事实错误、虚假功效、行业错误不能被其它高分抵消**（方案 §10.3）。
