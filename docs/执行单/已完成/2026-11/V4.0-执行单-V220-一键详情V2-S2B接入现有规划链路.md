## 2. 已确认产品决策（9 条，逐条锁定）

1. 商品图片是**唯一必选输入**，其它资料与设置均可选；
2. **count 由用户指定**，硬约束（1–12，默认 8），AI 不增不减；
3. 无板块时 AI 自主规划指定屏数内的内容与视觉，**禁止回退固定标题轮转**；
4. 首屏海报是默认核心任务（hero），但不写死标题与正面居中构图；
5. 质检是**独立可选按钮**，用户可跳过直接生图；
6. 质检建议**不自动覆盖**用户已确认的提示词；
7. 不增加叙事偏好/视觉偏好等额外**必填**设置；
8. 不新增第二套 Provider / API Key / 模型网关 / 图片生成系统；
9. 不破坏旧版一键详情功能——**空选时与改造前逐字节一致**（沿用 V214 口径，见 §5.4）。
