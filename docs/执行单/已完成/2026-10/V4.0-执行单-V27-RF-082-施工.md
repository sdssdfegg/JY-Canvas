## 3. 施工硬约束（改两巨石的既有纪律）

- **禁整体搬迁重组** main；**禁 Edit 整文件改写**（CRLF→LF 致 diff 万行）⇒ node 脚本按锚点打补丁。
- **逐行保留行尾**：`split("\n")` 剥尾 `\r` 记 cr，写回补回 ⇒ **CRCR 必为 0**。
- 锚点用 `startsWith`；插入段本身也进 drop 集。
- 提交：`git diff --ignore-cr-at-eol > p.patch` → `apply --cached --recount --ignore-whitespace` → `commit`（**不带 `-a`**）→ `checkout -- <f>`。
  🔴 该 apply **静默吞纯空行**：提交后仍脏 ⇒ 别改代码，`checkout --` 对齐 HEAD 并记账。
- **随迁常量按原行号升序搬**（`const` 不提升，乱序必 TDZ）。
- **只 `git add` 本单文件**，禁 `git add -A` / `git add src/`。
