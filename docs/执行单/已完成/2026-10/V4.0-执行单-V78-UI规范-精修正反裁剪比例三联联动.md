## 1. 需求（用户原话转译，2026-10-16 23:4x）

"把精修上方的裁剪按钮放在正反按钮的背后，和正反按钮一起联动，选择正反就开启了剪裁，关闭正反剪裁也关闭了，就是正反 裁剪 4:3 三个是一起联动选择的，剪裁只有开启正反才会启动。"

拆解为四条硬规则：
- R1 **归位**：裁剪钮从结果区头部移到精修设置区"正反"开关旁边（同一行，"背后"= 紧邻正反钮）；
- R2 **联动开**：正反 off→on 时，裁剪自动开启（splitHalves on）；
- R3 **联动关**：正反 on→off 时，裁剪自动关闭（splitHalves off）；
- R4 **单向门**：正反关闭状态下，裁剪钮不可手动开启（disabled）；正反开启后裁剪可手动切。
- 附：4:3 比例保持现有联动（正反 on 切 4:3、off 恢复原比例）——三者成为一个联动组。

- `.whiteRefineSplit`/`.whiteRefineSplitSwitch`/`.whiteRefineSplitNote` 的 CSS 规则：迁移到正反行上下文后若选择器失效，**改用/合并到 `.retouchIntentRow` 行内样式**（回报注明；禁止为迁就旧位置保留旧结构）。

### 3.2 三联联动（R2/R3/R4）

- 联动实现在 `patchRetouchIntent`（`use-outfit-settings-intent.js:217-239`）的 frontback 分支内扩展（与 4:3 联动同一处，保持"唯一改动入口"）：
  - frontback off→on：除切 4:3 外，**同步置 splitHalves = on 并持久化**（`setSplitHalves(true)` + `writeSplitHalvesEnabled(true)`——若该 hook 内不可达，则由 `outfit-workflow.jsx` 的 patch 包装处统一协调，回报注明实现位置）；
  - frontback on→off：同步置 splitHalves = off 并持久化；
- R4 单向门：裁剪钮 `disabled={retouchIntent.frontback !== "on"}`，disabled 态沿用 `.ui-button` 体系的视觉惯例（opacity + not-allowed）或开关既有 disabled 样式（回报注明）；
- 手动优先级：正反 on 时，裁剪钮可自由切（splitHalves 独立于 frontback 的细调），**不受**正反后续操作影响（除正反再次切换）。

### 3.3 文案与提示

- 裁剪钮 title 保留并吸收 `splitNote` 的关键信息（"把生成的结果从中线竖切成左右两张，分别保存；开启正反时自动开启"）；
