# V4.0 执行单 · V102 · UI规范·共享面⑤——Panel/ModuleHeader 扩散②（换装区头部标准化）

> 本单为第⑤项「Panel/ModuleHeader 扩散」的续片（V101 为 OutfitSettingsModal 单文件试点）。
> 范围锁定**换装（outfit）功能版块**内所有 bespoke 分区/模块头，统一迁到共享 `ModuleHeader`（V73 已支持 `icon/title/subtitle/action`，与换装区「标题 + 描述 + 右侧尾节点」三元组天然对应，无需扩展共享组件）。

## 0. 背景与判据

- 总纲 §9 队列第⑤项「Panel/ModuleHeader 扩散」。V101 已在 `OutfitSettingsModal.jsx` 完成试点（skinBlock/debugBlock → Panel + ModuleHeader，accepted visual delta）。
- 换装区仍散落 9 处 bespoke 头部，且存在类名与共享组件**同名碰撞**：bespoke `<header className="moduleHeader">` vs 共享 `<ModuleHeader>`。这是最强的「该统一」信号。
- 共享 `ModuleHeader`（V73）契约：`<ModuleHeader icon title subtitle action divider />` → 渲染 `<div class="ui-module-header"><span __icon/><div __text><span __title/><span __subtitle/></div><span __action/></div>`。`action` 右对齐（`margin-left:auto`），正好承接换装头的「右侧尾节点」（操作钮 / 计数 / icon）。
- 排除项（不属本单、不同语义）：
  - `outfit-panels.jsx:833` UploadZone 头 —— 含可编辑标题按钮 + 动态 hint，属**动态头**，保留 bespoke。
  - `OutfitComposer.jsx:253` `composerHeader` —— 是**标签页栏**，非分区标题，保留。
