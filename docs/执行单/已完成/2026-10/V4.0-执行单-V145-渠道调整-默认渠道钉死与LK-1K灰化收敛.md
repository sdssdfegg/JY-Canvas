## 1. 实际落地方案（approach B，已实施）

### 1.1 服务端计费修正（154.9.255.54）
- 文件：`/opt/new-api/data/one-api.db` 的 `options.billing_setting.billing_expr`。
- 在 `tt-image-2.5` 表达式的"默认(最低价)"分支前插入两行（按 channelId 阶梯，全局一份）：
  ```
  param("channelId") == "silent-tt25-line-10" ? tier("LY满血版", 0.14 * 1000000) :
  param("channelId") == "silent-tt25-line-11" ? tier("LK-1K", 0.12 * 1000000) :
  ```
- 备份：`one-api.db.bak-tt25-billing-fix-20261030-123941`。**已即时生效**，不影响其它渠道（其它渠道仍落默认 0.10 档）。
- 后续验证：LK 实测扣 0.12、LY 扣 0.14 正确（见 `P0-退出报告`/适配器 `adapter.log` 计费字段）。

### 1.2 前端"官方渠道"钉死 + 取消价格排序（①）
- `src/shared/routing.js:126-136` 新增 `OFFICIAL_CHANNELS`（与 `server/channel-config.js:24-34` 同源同步）：TT2.5 官方组 = `[silent-tt25-line-10]`（LY满血版）；LK-1K 按用户要求移出官方组、归"其他渠道"。
- `src/shared/routing.js:435-453` `channelsForModel`：改为"官方渠道按 `OFFICIAL_CHANNELS` 人工顺序置顶，其余按配置数组顺序展示"，**不再做价格升降序**。
- `src/shared/routing.js:455-463` `defaultChannelForModel`：默认渠道优先取首个官方渠道，回退 `MODEL_DEFAULT_CHANNEL`，再回退列表首条。
- `src/shared/routing.js:531-546` 新增 `splitOfficialChannels`（官方组 / 其他组拆分，供 UI 分组渲染 + 虚线隔断）。
- `server/channel-config.js:339-359` `publicRoutingChannels`、`:501-508` `publicRoutingCatalog` 同步改官方置顶、取消价格排序。
- `src/shared/models.js:22-24`、`:168` 与 `server/channel-config.js:240` 模型级 `quality` 去掉 `xhigh`（与上游能力一致）。
- `src/shared/routing.js:79-83` 与 `server/channel-config.js:73-81`：`HIDDEN_CHANNEL_IDS` 增加 `silent-tt25-line-09`（云枢高质量，用户要求隐藏）。

### 1.3 LK-1K 参数收敛与灰化（②）
- **根因**：此前 `normalizeChannelRow` 只拷贝渠道级 `sizes`、漏拷 `quality`，导致走目录路径的 LK-1K 质量声明丢失、high/max 未置灰（尺寸却生效，不对称）。
- `src/shared/routing.js:327-334` `normalizeChannelRow`：补拷贝渠道级 `quality`（与 `sizes` 对称）。
- `src/shared/routing.js:374-376` `FALLBACK_MODEL_CHANNELS`：LK-1K 声明 `sizes:["1K"]`、`quality:["auto","low","medium"]`、`official:true`。
- `src/shared/routing.js:499-520` 新增 `qualitiesForChannel`（与 `sizesForChannel` 同模式：渠道声明 quality 则取"模型 ∩ 渠道"）。
- `src/shared/routing.js:569-591` `convergeSettingsForModel`：切到限质量/限版本/限背景渠道时，把已选但不支持的档落回首个可用档（防界面与实际发出参数不一致）。
- `src/features/main-app/main-handlers.js:98-104` 与 `src/features/outfit/use-outfit-settings-intent.js:65-78`：切换渠道后调用 `convergeSettingsForModel(..., {preserveChannel:true})` 只重算渠道相关字段。
- UI 置灰：`src/features/main-app/panels/main-canvas-board.jsx:415-449`（尺寸/质量下拉 `disabled` 非允许项）、`src/features/outfit/panels/OutfitComposer.jsx:453-507`（换装入口同模式）、`src/features/outfit/outfit-workflow.jsx:409-418,1385-1391`（透传 `outfitSizesAll/outfitQualitiesAll`）、`src/shared/ui/ChannelPicker.jsx:86-108`（通用选择器）。

1. **计费**：LK 实测扣 0.12、LY 扣 0.14（154 `adapter.log` 计费字段确认），其它渠道不变。

4. **门禁**：`check-syntax` / `routing-check` / `http-mock-check` / `size-ratchet` 全绿，`vite build` EXIT=0。
5. **回归**：旧包误带 2K/high 被适配器拒的"参数不支持"已不再发生（前端收敛 + 服务端不降级）。
