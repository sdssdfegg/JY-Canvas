## 2. 阶段 A —— 隐藏降频 + 切回补查

两个文件的轮询循环同样改法（**只加节奏控制，不动状态更新逻辑、不动常量**）：

```js
      // V53：页面不可见时降频（双倍间隔），切回前台立即补查一次。
      // 不停止轮询——视频任务结果还要收；只是不空转。
      if (document.hidden) {
        await sleep(VIDEO_STATUS_POLL_INTERVAL_MS * 2);
        continue;
      }
```

并在轮询函数开始时注册（函数退出时清理，跟随该函数所在 hook/effect 的生命周期，以实际代码结构为准）：

```js
      let resumePoll = () => {};
      const onVisibilityChange = () => {
        if (!document.hidden) resumePoll();
      };
      document.addEventListener("visibilitychange", onVisibilityChanged);
      // ……在函数的返回/清理处：document.removeEventListener("visibilitychange", onVisibilityChanged);
```

`resumePoll` 的语义：**立即触发一次 status 查询**（不等下一个间隔），完成后复位为空操作，避免重复补查。具体挂法以两个函数的实际结构为准（composer 是返回对象的工厂函数、outfit-panels 在组件内），**保持两处行为一致**。

**不要动的**：`VIDEO_STATUS_POLL_INTERVAL_MS` / `VIDEO_STATUS_MAX_POLLS` 常量、`isVideoTaskCompleted` / `isVideoTaskFailed` 判定、`setVideoTasks` 状态更新、`shared/video-task.js` 的任何导出（别名导入关系是登记过的，动了会红）。
