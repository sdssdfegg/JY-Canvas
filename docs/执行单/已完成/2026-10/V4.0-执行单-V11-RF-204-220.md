### 0.2 ✅ 注册顺序的精确口径（本批新增 —— 因为路由被互相夹住）

1. **同一模块内部**的路由**相对顺序逐字保持**；
2. **所有路由仍必须在全部 `app.use` 中间件之后**；
3. **不得跨越任何通配 / 兜底路由**（如 `app.get("*")`、SPA 回落）；
4. 若某单的路由被别的路由夹住 ⇒ **在该单"第一条路由"的位置插入注册调用**即可；
   🔴 但**必须在 commit message 里列出「旧顺序 vs 新顺序」的差异点**，并说明"**路径不同、无通配重叠、故功能等价**"。
   （只允许这种"证明过等价"的位移；任何**跨中间件、跨通配路由**的位移一律禁止。）
