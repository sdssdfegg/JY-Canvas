## 2. 阶段 A —— V47 临时文件清理（commit 1）

只改 `server/core/history-store.js` 两处：

**A-1**：第 20 行 import 加 `unlink`：

```js
import { copyFile, mkdir, readFile, readdir, rename, stat, unlink, writeFile } from "node:fs/promises";
```

**A-2**：`writeHistoryFileAtomic`（当前 :291-295）改为：

```js
async function writeHistoryFileAtomic(file, text) {
  const temporary = `${file}.${process.pid}.${Date.now()}.${Math.random().toString(36).slice(2, 8)}.tmp`;
  try {
    await writeFile(temporary, text, "utf8");
    await rename(temporary, file); // rename 覆盖已存在文件，原子替换
  } catch (error) {
    // V55：rename 失败（典型：Windows 下目标文件正被其他程序占用/锁定）时必须清掉
    // 临时文件，否则 data/ 里会永久积累 .tmp 残渣。unlink 失败不掩盖原始错误。
    await unlink(temporary).catch(() => {});
    throw error;
  }
}
```

**只动这两处**，其余函数（`enqueueHistoryWrite` / `writeHistoryResultsUnlocked` / `appendHistoryResults` 等）一行不碰。

## 4. 阶段 C —— 验证

### C-1. rename 失败无残渣（核心验收，隔离沙盒）

原理：把沙盒 `data/history.json` 建成**目录**，`rename(文件 → 已存在目录)` 必然失败，从而确定性地触发 catch 路径（跨平台有效，无需 monkeypatch）：

```bash
cd "D:/源码开发/静音AI画板v4.0源码"
rm -rf tmp/v55-smoke
JINGYIN_RELEASE_ROOT="$PWD/tmp/v55-smoke/root" ./runtime/node/node.exe -e "
const fs = require('node:fs');
(async () => {
  const paths = await import('./server/core/app-paths.js');
  const store = await import('./server/core/history-store.js');
  fs.mkdirSync(paths.dataDir, { recursive: true });
  fs.rmSync(paths.historyFile, { force: true, recursive: true });
  fs.mkdirSync(paths.historyFile); // 占位：rename 必然失败
  try { await store.writeHistoryResults([]); console.log('UNEXPECTED: no throw'); }
  catch (e) { console.log('threw as expected:', e.code || e.message); }
  const residue = fs.readdirSync(paths.dataDir).filter((f) => f.endsWith('.tmp'));
  console.log('tmp residue:', residue.length, residue.join(','));
  fs.rmdirSync(paths.historyFile);
})();
"
```

> `JINGYIN_RELEASE_ROOT` 必须在 `import` 之前生效（`app-paths.js:50` 最高优先级读它），所以用环境变量前缀启动，**不允许先 import 再设**。期望输出：`threw as expected: ...` + `tmp residue: 0`。跑完确认真实 `data/` 无新增 `.tmp`（`ls data/*.tmp 2>/dev/null` 为空）、沙盒可留可删。
