## 2. 阶段 A —— 4 个僵尸断言脚本改多源（一个脚本一个 sub-commit）

> **总原则（铁律①活标本）**：这些 check 往往是**多源 `&&`**——定义搬了，调用点不一定跟着搬。**只把文件路径改到新文件，会把仍留在旧文件里的那部分断言变成新的僵尸。**
> 所以统一做法：**新旧文件一起读、拼接成一个字符串再断言**，并对"只应存在一份"的定义加唯一性断言。

通用改法模板（`node:fs` 需导入 `existsSync`，`reference-gate-check` / `retouch-intent-check` / `ui-duplication-check` 目前只导入了 `readFileSync`，要补）：

```js
  path.join(ROOT, "src", "outfit-workflow.jsx"),

];
const src = SOURCES.filter(existsSync).map((file) => readFileSync(file, "utf8")).join("\n");
```
