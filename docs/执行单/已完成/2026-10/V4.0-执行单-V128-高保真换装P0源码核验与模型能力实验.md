### 1.3 P0-B 模型能力实验（六项，总纲 §7，用现有画板 + 现有中转）

| 实验 | 要回答的问题 |
|---|---|
| 双图参考忠实度 | 同一 A/B、参数尽量一致，GPT 2.5 vs 香蕉 Pro：谁更忠实还原服装？谁更易把 B 模特身材迁给 A？ |
| Mask 实际语义 | 有/无 Mask 对照：Mask 外的人体、脸、手、背景是否仍漂移？（**人体保护主路径的生死点**） |

| 尺寸与可复现性 | 宽高比/输出规格/seed/重复调用波动 |
| 视觉分析可用性 | pose/quality/master-fit 输出能否支撑区域约束；是否必须新增分割能力 |
| 成本/限流/稳定性 | 各模型+线路的耗时、成本、错误码、限流与重试表现 |

## 2. 执行纪律（总纲 §16 红线摘要）

- **不改业务代码**；不引入 Python 服务 / PostgreSQL / 独立对象存储 / 另一套队列 / 新依赖（确有必要先写 ADR + 用户批准）。

- 不凭模型名推断能力；不以上传成功推断生效；不以单张成功推断批量稳定；不把视觉模型自评分当唯一真值。
- 用户态纪律：不碰用户浏览器既有状态；实验用受控样本资产，不删不改用户数据；遵守封装四红线（零 KEY/零生图记录/模板永不清/页面状态以用户为准）。
- 日志记资产引用与哈希，不复制大块图片数据或完整高敏提示词。
- 小步可验证：每个实验一份记录；文档类改动跑既有门禁（`--fast`）；未触碰 src 则 size-ratchet 不触发。
