## 1. 背景：V5.0-011「维持不拆」结论的复核修订

V5.0-011 §1 表对预览弹窗域的结论是「维持不拆：`closePreviewModal` 须早于 usePreviewDrag(327)，而 `navigatePreview` 依赖 `resultPreviewTasks`(492，晚于 327) ⇒ 拆分必须给共享 hook 入参加 ref 晚绑定，20 行收益不成比例」。NEXT.md 候选① 把该 wiring 成本写成明确方案（`clearSelectionRef` 式晚绑定改 usePreviewDrag 入参）后重新取证（2026-10-24，现行 1532 行结构）：

| 函数 | 定义行 | 消费方 | 时序性质 |
|---|---|---|---|
| `closePreviewModal` | 1053–1056 | usePreviewDrag ctx(333 `closePreview:`) | **仅 endPreviewDrag 指针事件期调用**（usePreviewDrag.js:44 `if (!drag.moved) closePreview();`）⇒ ref 晚绑定安全 |
| `navigatePreview` | 1058–1064 | useOutfitEffects ctx(656) 的 E28 keydown + JSX ResultPreviewModal prop(1492) | E28 闭包（deps `[preview, resultPreviewTasks]`）+ JSX prop |
| `zoomPreviewByWheel` | 1066–1070 | JSX ResultPreviewModal prop(1488) + imageLightbox onWheel(1513) | 纯 JSX prop |

**相对 V5.0-011 结论的五个修订点**：
1. usePreviewDrag 对 `closePreview` 的唯一调用在 `endPreviewDrag` 指针事件里 ⇒ 入参改 `() => closePreviewRef.current?.()` 事件期读取恒新，行为零变化（V5.0-010 `clearSelectionRef` 同族手法；取引用再调用语义，勿退化成 `() => ref.current`）；
2. `useOutfitEffects`(632) 调用点**晚于** `resultPreviewTasks`(449) ⇒ 只要 hook 调用点落在 (449, 632) 区间，useOutfitEffects ctx 收**真实 const**（无需包装）——E28 闭包语义比 ref 包装更保真，其依赖数组逐字不动；
3. `ResultPreviewModal` 是普通函数组件（**非 memo**）⇒ props 函数身份每渲染重建的行为与现状零差异；
4. 三函数**零 import 依赖**（仅 state/setter 与派生值）⇒ 组件 import 区零摘除，手术面比 V5.0-011 更小；
5. 本 hook 为纯函数工厂（内部无任何 React hook）⇒ 无 hook 顺序影响。

**时序约束唯一交集**：hook 调用点须晚于 449（ctx 取 `resultPreviewTasks`）、早于 632（useOutfitEffects 渲染期消费 `navigatePreview`/`closePreviewModal`）⇒ 置于 `useOutfitPageSwitch` 块(610–631) 之后、`useOutfitEffects`(632) 之前。

## 2. 目标域与方案

**方案：逐字搬迁 + 引用方直改**（同 RF-080/081/082、V5.0-008/009/010/011 先例，不留 re-export 壳）：

1. 新建 `src/features/outfit/handlers/outfit-preview-modal.js`，export `useOutfitPreviewModal(ctx)`，三函数按原声明顺序（closePreviewModal → navigatePreview → zoomPreviewByWheel）逐字搬入；
2. 组件侧 `src/outfit-workflow.jsx`：
   - import 区增一行 `useOutfitPreviewModal`；
   - `const closePreviewRef = useRef(null);` 声明于 `previewDragRef`(322) 旁（消费方 usePreviewDrag 紧邻其下，同 refreshSaveDirectoryRef/clearSelectionRef「声明在前」惯例）；
   - usePreviewDrag 入参 `closePreview: closePreviewModal` → `closePreview: () => closePreviewRef.current?.()`；
   - `useOutfitPreviewModal` 调用点置于 useOutfitPageSwitch 块之后 / useOutfitEffects 之前，紧随解构写刷新点 `closePreviewRef.current = closePreviewModal;`（每渲染刷新，同 clearSelectionRef:837 惯例）；
   - 摘除原 1053–1070 三个函数声明（保留 1072「预览平移拖拽…已统一由 usePreviewDrag 提供」注释）；
3. `useOutfitEffects` ctx 入参 `navigatePreview, closePreviewModal`(656) 不动（真实 const）；E28 依赖数组 `[preview, resultPreviewTasks]` 逐字不动。
