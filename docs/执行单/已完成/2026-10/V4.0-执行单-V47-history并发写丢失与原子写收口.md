## 2. 阶段 A —— 读-改-写整体串行（进程内锁）

**设计要点（先读懂再写，写错会死锁）**：

- 锁的粒度是**整个 append 的读-改-写序列**。只锁“写”不锁“读”没用：两个 append 都基于旧 current 计算，串行写仍然丢条目。
- 分两层：`writeHistoryResultsUnlocked()`（纯原子写，**内部不调任何读函数**）+ 对外的 `writeHistoryResults()`（入链）。
- `appendHistoryResults` 整体入链后，内部只能调 `writeHistoryResultsUnlocked`——**绝不能**调入链版的 `writeHistoryResults`，否则自己等自己，死锁。
- `readHistoryResults()` 自身**不入链**（它是纯读）；它内部的恢复路径（`:267`/`:273`）调用写入时用入链版，安全（链外等待链内，不会环）。
- 锁要“失败也继续排”：前一个任务抛错不能堵死后续所有写入。

参考实现（按本文件现有代码风格微调后落入，位置放在 `writeHistoryResults` 之前）：

```js
// V47：history.json 的读-改-写必须整体串行——批量出图的 append 是即发即忘的，
// 两个 append 交错时后写者会基于旧 current 计算，把先写者的条目静默吞掉（丢历史）。
// 参照 server/core/asset-persist.js 的 withSaveFilenameLock 范式；失败也继续排。
let historyWriteChain = Promise.resolve();

function enqueueHistoryWrite(task) {
  const run = historyWriteChain.then(task, task);
  historyWriteChain = run.then(() => {}, () => {});
  return run;
}

async function writeHistoryFileAtomic(file, text) {
  const temporary = `${file}.${process.pid}.${Date.now()}.${Math.random().toString(36).slice(2, 8)}.tmp`;
  await writeFile(temporary, text, "utf8");
  await rename(temporary, file); // rename 覆盖已存在文件，原子替换
}
```

import 区补 `rename`（当前 `:20` 从 `node:fs/promises` 导入的是 `copyFile, mkdir, readFile, readdir, stat, writeFile`）：

```js
import { copyFile, mkdir, readFile, readdir, rename, stat, writeFile } from "node:fs/promises";
```

改造点（**只动这三个函数，其它函数一律不碰**）：

1. `writeHistoryResults`（`:278-285`）拆成：

```js
async function writeHistoryResultsUnlocked(results, options = {}) {
  const normalized = (Array.isArray(results) ? results : []).map(normalizeHistoryItem).filter(Boolean);
  await mkdir(dataDir, { recursive: true });
  await writeHistoryFileAtomic(historyFile, JSON.stringify(normalized, null, 2));
  if (normalized.length > 0 || options.replaceBackup) {
    await writeHistoryFileAtomic(historyBackupFile, JSON.stringify(normalized, null, 2));
  }
}

export async function writeHistoryResults(results, options = {}) {
  return enqueueHistoryWrite(() => writeHistoryResultsUnlocked(results, options));
}
```

（注意：原实现 `writeFile(..., "utf8")` 的 utf8 参数在新函数里由 `writeHistoryFileAtomic` 统一带，语义等价。）

2. `appendHistoryResults`（`:348-364`）：函数体整体包进 `enqueueHistoryWrite`，内部把 `await writeHistoryResults(results)` 换成 `await writeHistoryResultsUnlocked(results)`。即：

```js
export async function appendHistoryResults(items) {
  return enqueueHistoryWrite(async () => {
    // ……原函数体原样保留，唯一改动：writeHistoryResults(results) → writeHistoryResultsUnlocked(results)
  });
}
```

3. `readHistoryResults`（`:246-276`）：函数体不动；它内部 `:267`/`:273` 两处 `await writeHistoryResults(backup)` / `(recovered)` 保持调入链版（正确，恢复写应排队）。
