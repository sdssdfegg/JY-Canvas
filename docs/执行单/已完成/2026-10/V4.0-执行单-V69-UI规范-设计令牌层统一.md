## 1. 需求（用户原话转译）

前端 UI 没有统一视觉、模块大小和视觉不统一、换装页不像亲生的。根因之一：**三套主题变量并存**——主应用 `styles.css` 的 `:root` 四套主题、换装 `outfit-workflow.css` 自带的 17 个硬编码变量、外加 250 处散写 hex。本单把令牌收口成单一来源，并让换装外壳归顺主题。

## 3. 改动要求

1. **新建 `src/styles/tokens.css`**（LF 行尾）：
   - 把 `styles.css:1-77` 的四套 `:root` 颜色主题**原值搬入**（默认/jade/graphite/mist，一个字节不改值）；
   - 新增尺寸族令牌（`--control-h-sm/md/lg`、`--radius-sm/md/lg`、`--space-1/2/3/4/6/8`、`--text-xs/sm/md/lg`、`--control-px`），以及 3 个新语义令牌 `--input`、`--control-bg`、`--accent-on`（取值见总纲 §11 与下方取值表）；
   - 新令牌取值（默认主题，其余三主题按同理各给值，浅色主题 `--accent-on` 用白字）：
     ```text
     --input: color-mix(in srgb, var(--panel-strong) 86%, transparent)
     --control-bg: color-mix(in srgb, var(--panel-strong) 86%, transparent)
     --accent-on: #061515（默认主题深色字，与现主应用 primary 按钮反白一致）
     ```
2. **`styles.css` 顶部改 `@import "./styles/tokens.css";`**，删掉自己的 `:root`/`:root[data-theme]` 颜色块（L1-77），其余不动。`main.jsx` 的 `import "./styles.css"` 保持不变。
3. **换装令牌归顺**（`outfit-workflow.css`）：删除 L1-23 的 17 个硬编码定义，在原位改为**别名映射块**（过渡期资产，注释标明"V69 别名映射·收口单删除"）：
   ```text
   --panel-bg: var(--panel);  --panel-strong-bg: var(--panel-strong);
   --input-bg: var(--input);  --button-bg: var(--control-bg);
   --text-soft: var(--muted); --accent-text: var(--accent-on);
   --accent-border: var(--accent); --option-bg: var(--panel-strong);
   --shell-bg: var(--app-bg); --sidebar-bg: var(--sidebar); --topbar-bg: var(--topbar);
   ```
   其余 804 处 `.outfitWorkflowEmbedded` 引用**一律不改**（别名透明承接）。
4. **换装外壳硬编码深色面改令牌**：`outfit-workflow.css:52-68` 一带的 appShell/sidebar/topbar/panel 的硬编码背景与边框（`#07090d`、`rgba(12,13,20,.92)`、`rgba(255,255,255,.08)` 等）改为对应令牌（`var(--app-bg)`/`var(--sidebar)`/`var(--border)`）；**双径向光晕**改为 `color-mix(in srgb, var(--accent) 14%, transparent)` 与 `color-mix(in srgb, var(--accent) 12%, transparent)`（两个光晕都从 accent 派生，粉色光晕并入 accent 族——总纲 §11 已列 accepted delta）。沿路其余硬编码"面"（背景/边框/文字色）同规则改令牌；**装饰性渐变停码与 hex 文字色不在本单范围**（V73 棘轮处理）。
5. **尺寸族只建不用**：本单不改任何现有控件的实际高度/圆角/间距取值（那是 V70/V71 的事），仅把令牌建好。现有 `min-height:30px/32px/36px`、`border-radius:7px` 等**原样保留**。
