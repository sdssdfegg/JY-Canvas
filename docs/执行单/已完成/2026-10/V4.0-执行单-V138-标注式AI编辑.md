用户需求：在快捷生成结果卡上补齐「悬浮操作」与「标注式 AI 编辑弹窗」四项能力（悬浮编辑/删除、标注弹窗、标注数据结构、局部视觉统一）。

- 原图像素**绝不修改**：提交时由 `annotationsToImageBlob` 生成「标注参考图」副本，作为一次性参考输入送入现有 `generate` 流程（不写 composer、不改 API Key / 模型 / 提示词模板 / 模型调用配置）。

## 2. 功能实现要点

- **Function 1（悬浮操作）**：`.assetHoverActions` 纯 CSS `:hover/:focus-within` 浮现，不触发卡片重渲染；「编辑」开标注弹窗，「删除」两步内联确认（先显「确认删除？」再点删除），避免误删。常驻 select/download/rerun/delete 保留作触屏/键盘入口。
- **Function 2（标注弹窗）**：矩形/圆/箭头/画笔拖拽绘制，6 色切换，撤销/重做（history/future 栈），下载「标注参考图」（不修改原图），「使用」提交。无伪禁用按钮。
- **Function 3（数据处理）**：区分 ① 原图 ② 标注对象+坐标 ③ 编辑指令 ④ 实际模型输入（标注参考图）⑤ 最终结果。标注与原始独立保存、仅作引导；提交走现有 `generate`（`replaceResultId` 原位覆盖、提示词=编辑指令、`extraReferenceFiles` 带标注参考图）。模型局部蒙版未启用，弹窗内明确标注该局限。
- **Function 4（局部视觉统一）**：仅动卡片 + 弹窗，复用 `--panel/--border/--accent/--text/--danger/--radius-*/--space-*` 等令牌，未引新样式变量，保留暗色主题 + 青色强调。

**箭头方向 bug（用户报"方向总是反的、只能朝右"）根因**：一轮为修「反向拖拽负宽高导致 SVG 不渲染」，我在 `onPointerUp` 提交时统一做了 `normalizeRect` 归一化——它把 `w/h` 的符号吃掉了，箭头方向（起点→终点）因此被翻转，且恒定指向右下。
修复：
- 箭头**保留 `w/h` 符号**（方向即方向）；只有矩形/圆在渲染时归一化成正尺寸（SVG `rect` 负宽高、`ellipse` 负半径不渲染）。
- 箭头头部改在**等比空间**计算：viewBox `0 0 1 1` + `preserveAspectRatio="none"` 下 x/y 缩放系数不同，直接在归一化空间算头部会被拉歪；现按图片 `naturalWidth/naturalHeight` 把 x 拉到等比空间，算完再映射回来。
- 新增 5 项回归断言（反向拖拽不翻转、头部靠近终点、向左拖拽仍向左、宽高比换算后两倒钩等距）⇒ `annotation-geometry-check` **33/33**。

**刻意不动的部分**：`.previewImageFrame` 全局规则未改，只给快捷预览新增 `.quickPreviewFrame{position:relative}` 作为定位上下文——批量预览的定位行为保持原样，避免波及既有导航箭头。
