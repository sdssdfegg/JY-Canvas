## 3. 改动要求

### 3.1 新建组件（`src/shared/ui/`，样式追加进 `ui.css`，LF 行尾）

1. **`Toolbar.jsx`**：`<Toolbar align="start|end" wrap gap>` → 渲染 `<div className="ui-toolbar ui-toolbar--{align}">`；flex + `gap: var(--space-2)` + `align-items:center`；`wrap` 为 true 时 `flex-wrap: wrap`；`gap` 可传数字覆盖（默认 8）。用于顶栏操作区、卡片操作行、弹窗 footer。
2. **`Field.jsx`**：`<Field label hint hintTone="default|danger|success" htmlFor>` → 渲染 `<label className="ui-field">`：`<span className="ui-field__label">{label}</span>` + children（控件原样嵌入）+ `{hint && <small className="ui-field__hint ui-field__hint--{tone}">{hint}</small>}`；label 12px muted、hint 12px faint（danger 用 `var(--danger)`、success 用 `var(--accent)`）、label 与控件 gap 6px、整项 grid。**必须保持 `<label>` 外壳**（原 `modalField` 就是 label，点击聚焦行为不能丢）。

两个组件的函数体保持 <50 行（size-ratchet）；props 用解构 + 默认值；`type` 等原生属性透传规则同 V70 `Button`。
