1. **分组间距**：精修面板的「对称」「衣摆或裙摆」「版型」三组之间空一点位置，让客户看得出哪几个 chips 是一组的。

   - 在通用提示词**最上面**插入固定段：`把图1和图2服装正反平铺俯视图电商白底精修，无缝纯白背景，清除所有拍摄道具和杂物，左右分开并列摆放，保持清晰间距，禁止重叠、穿插、互相压盖或合并成一件。`
   - **联动出图比例 4:3**；再点一下取消，**恢复激活前的比例**，提示词段消失。

## 3. 改动要求

### A. 分组间距（最小改动）
- 改 `retouch-intent.css:17`：把三行之间的视觉间隔拉开（如 column-gap 14px → 20~26px），或给 `.retouchIntentRow:not(:last-child)` 加右间距/分隔。**不重构数组结构、不加新组**；具体数值执行者自定，回报附截图或间距值。

### B.「正反」开关
1. `retouch-intent.js`：新增固定段常量 `RETOUCH_FRONTBACK_TEXT`（用户文案，一字不改）；intent 新增字段 `frontback: "off" | "on"`（默认 `"off"`），补进 `normalizeRetouchIntent` / `validateRetouchIntent`（用 retouch-intent.js 内 `off/on` 五件套先例 `:16-24` 的写法）。
2. `compileRetouchPrompt`：`frontback === "on"` 时在 `sections` **最前**（`【用户补充】`之前）插入 `{ id: "frontback", title: "【正反视图】", body: RETOUCH_FRONTBACK_TEXT }`；off 时不产生任何输出（**v1/默认路径逐字节不变**——这是硬验收）。
3. `autoChars`（`:190-192`）必须把新段计入；若开启后超 `RETOUCH_AUTO_PROMPT_CHAR_LIMIT=600`，允许把上限上调至实测值 +10% 并在 commit message 写明 reason（**此为本单唯一获准的常量调整**）。
4. **比例联动放 hook 层，不改 props**：在 `use-outfit-settings-intent.js` 的 `patchRetouchIntent` 内检测 `frontback` 从 off→on：用 `useRef` 记录当前 `aspectRatio`，同一次 `setSettings` 里合并 `aspectRatio: "4:3"`；on→off 时恢复 ref 记录的比例。**禁止**给 `RetouchIntentPanel` 新增 props、禁止改 `OutfitComposer.jsx` / `outfit-workflow.jsx` 传参（文件交集控制）。
5. UI：`RetouchIntentPanel.jsx` 版型行之后加一个独立 toggle 按钮（文案「正反」，激活态沿用 chip 的 active 样式或 `whiteRefineSplitSwitch` 滑块样式，二选一）；**不要**新增 `retouchIntentChips` 类名的第四组（见门禁）。

### C. 服务端校验确认（必做，只确认不改逻辑）
- 确认 `server/routes/outfit.routes.js:278-293` 的 `validateRetouchIntent` import 自哪个文件；若是同一份 `src/shared/retouch-intent.js` 则自动通过；若服务端有独立副本，**两份都必须补 `frontback` 字段**，否则开启正反后请求直接 400。回报写明结论。
