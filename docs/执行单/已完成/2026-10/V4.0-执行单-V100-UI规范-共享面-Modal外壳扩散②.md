## 0. 背景

V99 已完成第④项 feature 层（7 处 `src/features/**` 壳改用共享 `Modal`）。本单收官第④项剩余部分——**V99 §1.5 单列 🔴 的 8 处主壳/outfit 壳**，并**同步改造 `modal-shell-check.mjs` 硬编码门禁**。

起草日 `git grep` 实测：

- `main.jsx` 仍有 **6 处** bespoke `div.modalLayer + section onMouseDown=stopPropagation` 弹窗壳：saveDirectoryModal / detailPresetModal / stitchPreviewModal（stitchLayer）/ referencePreviewModal / uploadPreviewModal / previewModal（closePreview）。
- `outfit-workflow.jsx` 仍有 **2 处**：promptAssistantModal（promptLayer）/ imageLightbox previewModal。

这 8 处被 `modal-shell-check.mjs` 的 `modalCounts.main === 0 && modalCounts.outfit === 0` **写死钉死**——该断言专为守护"裁剪/局部回贴弹窗（quickCrop/outfitPanel/localEdit 三个承载文件）不被搬回 main/outfit"而设。V100 必须把该断言更新为迁移后的实际计数（main=6 / outfit=2），**同时保留**裁剪/局部回贴的三处守卫（`quickCrop===1 / outfitPanel===1 / localEdit===1` 及 `main/outfit` 仍引用 `<LocalEditModal>` 的 `includes` 断言），使门禁语义从"这两个页不许有 `<Modal>`"转为"这两个页的 `<Modal>` 数量必须恰好等于迁移数（防止误加/误删、防止双份）"。

## 1. 改动要求

### 1.1 策略：只换壳，保留原 `<header>` 作 children（DOM 逐字节等价，零视觉变化）

与 V99 §1.1 同口径。共享 `Modal` 渲染为：

```jsx
<div className={layerClassName} onMouseDown={onClose}>
  <section className={panelClassName} onMouseDown={(event) => event.stopPropagation()}>
    {children}
  </section>
</div>
```

→ 把每处 bespoke 壳的 `div.modalLayer[ EXTRA] onMouseDown={X}` + `section SOMEPANEL onMouseDown={stopPropagation}` **整体替换为** `<Modal layerClassName="modalLayer[ EXTRA]" panelClassName="SOMEPANEL" onClose={X}>`，原 `<header>` 与 children **原样留在 `<Modal>` 内部**。`<Modal>` 自带 `onMouseDown` 行为（layer→`onClose`、section→`stopPropagation`），children 内不再需要 bespoke `section`。

- **不使用 `ModalHeader`**：main 侧 6 壳现用关闭钮 `X size={18}`，outfit 侧 2 壳现用 `X size={16}`；`ModalHeader` 硬编码 `size={16}`，改用即把 6 个主壳视觉变为 16。故**头部原样保留**，仅换外层壳（与 V99 同口径，零视觉变化）。
- **保留 `<header>` 内的 `h2` / `span` / 关闭 `<Button iconOnly>` 的 `X` 尺寸与 `aria-label`** 完全不变。

### 1.2 🔴 最高约束：类名与 DOM 结构零改动（壳层）

- **必须原样保留**：所有 `panelClassName`（saveDirectoryModal / detailPresetModal / stitchPreviewModal / previewModal / referencePreviewModal / promptAssistantModal）、`layerClassName` 附加类（stitchLayer / previewLayer / promptLayer）、`<header>` 结构、`X` 尺寸、文案。
- 共享 `Modal` 已自带 `onMouseDown` 行为，**不得**在 children 里再加/改这些 handler。
- **必须改造 `modal-shell-check.mjs`**（见 §1.5）：这是本单与 V99 的唯一本质区别，且为 🔴 风险点。

### 1.4 逐文件动作

- **补 import**（不带 `.jsx` 后缀，仓内惯例）：`src/main.jsx`（现有 `AppSidebar` 用 `./shared/ui/AppSidebar`）加 `import { Modal } from "./shared/ui/Modal.jsx";`；`src/outfit-workflow.jsx`（现有 `Button` 用 `./shared/ui/Button`）加 `import { Modal } from "./shared/ui/Modal.jsx";`。
- **替换壳**：每处按 §1.1 / §1.3 把 `div.modalLayer[ EXTRA] + section` 两行开标签换成 `<Modal ...>` 一行开标签；对应**最外层**闭合 `</section>\n <indent></div>` 换成 `</Modal>`（注意只换该壳外层闭合，别误伤壳内嵌套元素：如 #4/#5/#6 的 `previewArrow` 按钮 `onClick`、#6 的 `previewPrompt` 按钮、#3 的 `CachedImage`/`stitchLongImage` 等）。
- **不改**任何 children（header / body / footer / 事件 / 文案 / 样式 class）。
