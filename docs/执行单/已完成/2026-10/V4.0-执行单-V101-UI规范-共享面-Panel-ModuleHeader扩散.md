## 1. 改动要求

### 1.1 策略：按 SettingsView 试点范式，把 bespoke 卡片 + 手写分区标题迁到共享 `Panel` + `ModuleHeader`（**有意重排，非零视觉变化**）

共享组件契约（起草日实测，执行日重测）：

```jsx
// Panel：<div className="ui-panel ui-panel--{tone} ui-panel--pad-{padding}">{children}</div>
//   .ui-panel = display:grid; gap:16px(--space-4); margin-top:14px; 1px border + radius-lg + --panel 底；> p 走 muted/12px/1.55
// ModuleHeader：<div class="ui-module-header[--divider]"><span class="__icon">{icon}</span><div class="__text"><span class="__title">{title}</span></div></div>
//   __title = 14px/500/--text；__icon = muted；与父 gap 8px
```

`skinBlock` 现状：`.skinBlock { display:grid; gap:8px; margin-top:14px }`（**无边框、无底色、无 padding**，仅标题块）；`.skinBlock > span` = `display:flex; gap:7px; color:muted; font-size:13px; font-weight:700`（手写分区标题）。`debugBlock` 现状同结构（`.debugBlock p` = muted/12px/1.55，与 `.ui-panel > p` 逐字等价）。

→ 把两处 bespoke 卡片整体改写为 `<Panel>` 包 `<ModuleHeader icon title />`，**对齐 SettingsView 试点**：

- 视觉 delta（**预期内、验收以截图记录**，非回归）：
  - 卡片外壳：无边框/无底色 → 带 `1px` 边框 + `radius-lg` + `--panel` 底 + `16px` padding（与 SettingsView 的"皮肤/连接测试"卡片一致）。
  - 内容 gap：8 → 16（Panel 栅格）。
  - 分区标题：13px/700/muted 行内 span → 14px/500/--text 的 ModuleHeader（icon + 标题分栏）。
  - `debugBlock` 连接状态 `hint`：由 Field 近标题处 → 仿 SettingsView 挪到操作钮之后（见 §1.3 #2）。

### 1.2 最高约束：类名与 DOM 结构**允许按试点范式变更**（本单与 V99/V100 的"零改动"本质不同）

- `.modalField` 规则**必须保留**（main.jsx:1147 仍用）。
