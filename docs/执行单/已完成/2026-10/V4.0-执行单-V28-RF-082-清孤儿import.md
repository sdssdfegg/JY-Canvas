## 1. 为什么有这张单

RF-082 把 7 个域的函数从 `main.jsx` 搬走后，**上游 import 没跟着清**。ESLint 实测：

```
src/main.jsx   26 warnings   ← 施工前是 5
   22  no-unused-vars        ← 新增，即本单要清的
    4  react-hooks/exhaustive-deps  ← 原有（其中 1 条随组件转移到 quick-crop-panels.jsx，合计仍 5）
```

门禁没拦住的原因：`no-unused-vars` 是 **warning 不是 error**，而 `lint-ratchet` 在本环境恒失败（`spawnSync` EBUSY）。⇒ **这是门禁盲区，不是施工方失误**，但必须清掉才能收工。
