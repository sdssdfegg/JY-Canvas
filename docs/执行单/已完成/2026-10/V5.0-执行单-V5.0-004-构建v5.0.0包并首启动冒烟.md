## 二、关键纪律（踩坑口径固化）
1. **必须用项目自带 node 跑构建**：SEA 单文件 exe 的基底 = "运行构建的 node"，而 esbuild target=`node24`、文档约定 v24.9.0。
   因此必须用 `D:/源码开发/静音AI画板v4.0源码/runtime/node/node.exe`（v24.9.0）跑 `build.mjs`，
   **不能用 workbuddy 的 node 22**（否则 exe 基底成 node22、与目标不符）。
2. **public 生产构建是 TDZ 触发点**：`secure-win-release.mjs` 的 `npm run build` 带 `VITE_JINGYIN_PUBLIC_RELEASE=1`，
   恰是 V121-R2 白屏的触发模式 → 发版前必须首启动冒烟（不只是 health 200，要真实浏览器加载抓白屏）。
