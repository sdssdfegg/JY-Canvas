## 0. 根因（已由真机快照确认，无需再查）

真机快照 `logs/launcher-failure-20261001-230004.log` / `-230055.log`：

```
Error [ERR_MODULE_NOT_FOUND]: Cannot find module '...\server\core\static-assets.generated.js'
  imported from '...\server\core\app-bootstrap.js'
```

`server/core/app-bootstrap.js` 第 **25** 行：

```js
import { EMBEDDED_STATIC_ASSETS } from "./static-assets.generated.js";   // ❌ 少了 ../
```

该生成物在 **`server/` 根目录**（`scripts/generate-static-assets.mjs:7` 也写在那里：`path.join(rootDir, "server", "static-assets.generated.js")`）。
从 `server/core/` 出发，正确路径是 **`../static-assets.generated.js`**。

> **这是 RF-116 的回归**，也是 RF-011（`app-paths.js` 少一层目录）的**同款病、相反方向**：搬进子目录后，**相对导入的层级没按新位置重算**。
