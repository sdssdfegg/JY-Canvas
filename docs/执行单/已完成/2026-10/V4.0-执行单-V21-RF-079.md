## 🔴 为什么这块的期望值比 main 侧更高

统筹用配平法实测（数据见下），本域有两个结构性特征：

```
outfit-workflow.jsx 共 10256 行 / 识别 365 个函数 / 函数体合计 7460 行（占 72.7%）
result·task 域名命中：83 个函数 / 1919 行
  ├─ indent=0（模块顶层）  42 个 / 700 行   ← ★ 关键
  └─ indent=2（组件内部）  37 个 / 1190 行
```

⭐ **indent=0 的 42 个（700 行）是「零 deps 薄壳」的直接可搬项**：它们定义在模块顶层、
不依赖组件 state ⇒ 搬走只需加 `export` + 在 outfit 里改一条 `import`，
**不需要 deps 对象、不需要薄壳、调用点零改动**。这比 main 侧（函数全在组件内，必须走 B3 工厂 + 薄壳）
成本**低一个数量级**。

⇒ **请优先、重点评估这 42 个**，它们的判定性价比最高。
