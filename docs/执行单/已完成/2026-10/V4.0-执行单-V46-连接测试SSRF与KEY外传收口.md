2. 在 `const apiKey = resolveApiKey(body.apiKey);` 校验**之后**、`probeUrl` 构造**之前**插入守卫：

```js
    // 产品规则（src/shared/image-hosts.js 头注释）：生图 API 只允许官方中转。
    // 连接测试带用户 KEY 出网，不收白名单就是 SSRF + KEY 外传原语。
    // 与生图链路同源判定：isLockedChannelBaseUrl 内部已做 normalizeBaseUrl。
```

3. 守卫的边界语义（写进代码注释或提交消息，便于后人）：

   - `requestedBaseUrl` 非空且命中锁定列表 → 行为不变；
   - 非空且未命中 → 400，**不发起任何出网请求**（守卫必须在 fetch 之前）；
   - 已有的 `^https?://` 校验保留（双保险，不动）。
