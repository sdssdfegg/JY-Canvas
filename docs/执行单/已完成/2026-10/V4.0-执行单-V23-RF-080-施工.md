## 4. 硬约束（违反即回滚）

1. **按原行号升序搬运**：闭包里大量 `const` 常量**不提升**，顺序乱了会 TDZ。按原序搬 ⇒ 天然保序。
2. **`CropModal` 必须先于或同批 `BatchResizePanel`**（后者在 4379 / 4395 处调用它）⇒ 否则新文件内 `no-undef`。
3. **`PromptPresetGrid` 必须是新文件的模块顶层**，不得塞进别的组件体内
   （源码注释硬约束：挪进组件内 ⇒ 每次 render 重建类型 ⇒ 搜索框失焦 / 拖拽态重置）。
4. **行尾逐行保留 CRLF**：`split("\n")` 剥 `\r`、写回补 `\r`，**`CRCR` 必须为 0**。
   提交：`git diff --ignore-cr-at-eol > p.patch` → `apply --cached --recount --ignore-whitespace` → `commit`（不带 -a）→ 看 `--cached --stat`。
   🔴 该 apply 会**静默吞纯空行**：提交后仍脏 ⇒ 别改代码，`git checkout --` 对齐 HEAD 并记账。
5. **清孤儿 import 只信 ESLint 实测点名**，不要照抄清单预测行数。
6. **新文件绑定别名必须照抄**：`constrainCropRect as sharedConstrainCropRect`
   （原文件是别名 import，写成原名 ⇒ `constrainLocalEditRect` 那行直接 `no-undef`）。

## 8. 人工冒烟（8 条高危 case，交付前逐条过）

| # | 场景 | 高危原因 |

| 5 | `UploadZone` 三处调用点(8505 / 8535 / 8604)：拖图落区、删除、**拖入非图片** | 32 个 props 最容易漏传 |
