## 4. 施工硬约束（改两巨石的既有纪律）

- **禁整体搬迁重组** outfit；**禁 Edit 整文件改写**（CRLF→LF 会致 diff 万行）⇒ 用 node 脚本按锚点打补丁。
- **逐行保留行尾**：`split("\n")` 后剥尾 `\r` 记 cr，写回时补回 ⇒ **CRCR 必须为 0**。
- 锚点判断用 `startsWith`；插入段本身也要进 drop 集。
- 提交写法：`git diff --ignore-cr-at-eol > p.patch` → `apply --cached --recount --ignore-whitespace` → `commit`（**不带 `-a`**）→ `checkout -- <f>`。
  🔴 该 apply 会**静默吞纯空行**：若提交后仍脏 ⇒ 别改代码，`checkout --` 对齐 HEAD 并记账。
- **只 `git add` 自己本单的文件**，禁止 `git add -A` / `git add src/`。
