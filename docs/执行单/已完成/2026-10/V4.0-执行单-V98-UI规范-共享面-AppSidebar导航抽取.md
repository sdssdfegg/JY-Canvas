## 0. 背景

UI 规范化进入总纲 §9 共享面抽取队列。前两项已完成：V90 `TaskBadge`、V91 `DetailUploadZone`。本单抽第③项——主壳左侧导航。

现状：`src/main.jsx` **L937-963** 内联了整段导航（`<nav className="navList">` + 设置入口 `<button className="settingsEntry">`），未走 `shared/ui/`。抽取后与其它共享面统一，并让 `main.jsx` 继续瘦身。

## 1. 改动要求

### 1.1 新建 `src/shared/ui/AppSidebar.jsx`

- **抽取范围（起草日实测）**：`main.jsx` L937-958 的 `<nav className="navList">` 整段 + L960-963 的 `settingsEntry` 按钮。**二者同属导航性质，一起抽**。
- **不抽**：`<aside>` 顶部品牌区（L930-935，`静音AI绘画` / 静音相伴 / 电话文案）——纯静态硬编码内容，抽了收益小、风险大，留在 `main.jsx`。
- **建议 API**（执行日可按实测微调，但须保持受控）：
  ```jsx
  AppSidebar({ navItems, activeView, onSelectView, onOpenPrompts, onOpenSettings })
  ```
  - `navItems`：由调用方传入（来源 `features/storage/storage-store.js` 的 `navItems`，保持现状不搬）。
  - 组件内保留 `item.id === "prompts"` 的特殊分支逻辑（打开提示词助手而非切视图），**判定逻辑一字不改**，通过 `onOpenPrompts` 回调上抛。
  - `activeView === item.id` → `.active` 判定逻辑一字不改。

### 1.2 🔴 最高约束：类名与 DOM 结构**零改动**

实测 `git grep -ln "navItem" -- src scripts` 命中 **6 个门禁脚本的探针页面**（`scripts/verify/` 下 `composer-stable-height-page.jsx`、`detail-stylepack-off-page.jsx`、`error-boundary-page.jsx`、`modal-shell-page.jsx`、`resize-long-edge-page.jsx`、`retouch-frontback-page.jsx`），统筹的 tabbit 复核探针也用 `.navItem` 做导航。

→ **必须原样保留**：`.navList` / `.navItem` / `.navItem.active` / `.subNavItem` / `.settingsEntry`，以及 `<button>` 元素类型、`type="button"`、`key`、`aria`/结构层级。**改任何一个类名都会让 6 个门禁脚本失效**（V83 教训：类名消失，上下文选择器随之失配）。

### 1.3 CSS 不随迁（沿用 V91 裁决）

`.navList`(L112) / `.navItem`(L119) / `.navItem.active`(L135) / `.subNavItem`(L140) / `.settingsEntry`(L163) 等在 `src/styles.css`（全局加载）。**组件搬、CSS 留原处**——搬样式是纯风险零收益。

### 1.4 `main.jsx` 侧

- 删除 L937-963 内联 JSX，替换为 `<AppSidebar … />`。
- 补 import：`import { AppSidebar } from "./shared/ui/AppSidebar";`（**不带 `.jsx` 后缀**，仓内惯例）。
- 若 `Settings` / 其它 icon import 因此变成未使用 → **真删**（不得 `eslint-disable`；停用代码用 `_` 前缀）。
- 更新 `src/shared/ui/README.md`，新增一行说明（与 TaskBadge / DetailUploadZone 同格式）。
- 注意 `main.jsx` 现有 CRLF 已归一为 LF，改动不会产生大 diff ✔。

### 1.5 不要顺手做的

- 不改任何视觉（本单是**纯搬移**，零视觉变化）。
- 不抽品牌区、不动 `navItems` 数据来源、不动 `storage-store.js`。
- 不做四主题/按钮/颜色等任何其它规范化。
