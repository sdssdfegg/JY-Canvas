## 3. 改动要求

1. **新建 `src/shared/ui/Button.jsx`**（LF 行尾；单文件函数保持 <50 行，规避 size-ratchet）：

   ```jsx
   // API：<Button size="sm|md|lg" tone="default|primary|danger|ghost" iconOnly loading active disabled title>…</Button>
   // - size: sm=28 工具栏 / md=36 版块内 / lg=44 页面主操作
   // - tone: default 灰面 / primary 实心 accent / danger 危险 / ghost 透明
   // - iconOnly: 正方形（aspect-ratio:1），children 直接放 lucide 图标
   // - loading: Loader2 旋转 + 自动 disabled；active: accent 淡底（tab 场景）
   // - 必须透传 onClick/type/title/aria-* 等其余原生属性
   ```

   实现要点：class 拼接 `.ui-button .ui-button--{size} .ui-button--{tone}` + 状态类；`disabled={disabled || loading}`；非 iconOnly 时文本包 `<span className="ui-button__label">`；`type` 默认 `"button"`。

2. **新建 `src/shared/ui/ui.css`**（LF 行尾；由 `Button.jsx` 顶部 `import "./ui.css"` 引入）：
   - 全部取值走 V69 令牌并带回退值（如 `var(--control-h-md, 36px)`），确保 V69 未合入时也可构建；
   - 变体：`.ui-button`（基础）/ `--sm`/`--md`/`--lg`（尺寸）/ `--default`/`--primary`/`--danger`/`--ghost`（色调）/ `--icon`（`aspect-ratio:1;padding:0`）/ `--active` / `--loading`；
   - 状态：hover（非 disabled）边框转 accent、文字转 `var(--text)`；primary hover 用 `--accent-strong`；`:disabled` 透明度 0.55 + `not-allowed`；`focus-visible` 2px accent outline；
   - `@keyframes ui-button-spin` 旋转动画，`.ui-button__spin` 挂载；
   - **只此一份按钮样式**，后续组件样式继续追加到本文件（`.ui-panel` 等，V72 用）。

3. **试点接入 `OutfitSettingsModal.jsx` 7 个按钮**（按总纲 §4.2 映射，弹窗内标准为 md）：

   | 行 | 现状 | 映射 |
