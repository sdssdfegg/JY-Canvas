## 7. 对照组（必须落 `scripts/dev/`，不得用 `tmp/`）

`scripts/dev/rf074-phaseA-control.mjs`（阶段 1）、`scripts/dev/rf074-phaseB-control.mjs`（阶段 2）。

每份必须包含：

1. **等价性主证**：BASE 版函数体（用 `git show <BASE>:src/main.jsx` **按行切片取原文，绝不手抄**）
   与搬进工厂后的函数体**逐行比对**（去 deps 解构行后应完全一致）。
2. **调用契约不变**：工厂返回的解构名集合 ⊇ 原调用点在用的名字（尤其 `blobFromImageItem`）。
3. **参数化反证**：改一处 deps 入参值 ⇒ **输出必须改变**（证明没有把某一侧写死）。
4. **负向对照**（缺一不可）：故意在工厂内删掉一个 deps 项的解构 ⇒
   必须命中 ESLint `no-undef` / 对照组 FAIL。⇒ 证明 harness 灵敏，**不是恒真断言**。
5. `async` 函数体抽取用 `Object.getPrototypeOf(async function(){}).constructor`，
   且抽取起点**从 `async` 算起**（用 `indexOf("function")` 会丢 async）。

输出格式沿用既有：`ALL PASS` / 逐条 `PASS|FAIL name`。

🔴 ESLint 负向对照注入后**不可用 `git checkout` 还原**（会连同未提交的修复一起丢弃）
⇒ 一律用 Edit 只删注入行。
