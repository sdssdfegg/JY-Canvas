## 3. 阶段 A1 —— 加 content-visibility

在对应样式文件给结果卡根类补（批量卡 `.assetCard` 已有规则块的话就并进现有块，不重复声明选择器）：

```css
.assetCard {
  content-visibility: auto;
  contain-intrinsic-size: auto 320px; /* auto = 浏览器记住上一次真实尺寸，缩放后自动校准 */
}
```

主画板结果卡同理（类名以 A0 输出为准，值同样用 `auto <高度>`，高度按该卡实际高度估，允许估粗略——`auto` 会自校准）。

**不要动的**：`.taskGrid` 的布局属性、`--asset-card-min` 变量逻辑（`:617` `galleryCardMin` 与缩放联动）——本单只加渲染提示，不改布局。
