### 1.4 提示词 4 处部位词实时整体联动（核心修复）

重写 `replaceRecolorPartWords`（同文件 `outfit-top.js`），**忽略 `fromPart`**，改为「按正文里实际出现过的部位类别词整体归一为新部位的词」：

```js
/** 把 prompt 里「实际出现过的部位类别词」统一替换成新部位的词（单部位改色：提示词里 4 处应为同一部位的词）。
   忽略 fromPart —— 直接按正文里出现过的部位词来换，这样即便之前手动改词导致状态与正文错位，
   只要正文里是某部位的词，切一次部位就能整体对齐；正文没出现过的部位词（如偶然提到的「鞋子不动」）不会被误伤。 */
export function replaceRecolorPartWords(prompt, _fromPart, toPart) {
  const toWord = (RECOLOR_PART_WORDS[normalizeRecolorPart(toPart)] || [])[0];
  if (!toWord) return String(prompt || "");
  let text = String(prompt || "");
  const presentWords = Object.values(RECOLOR_PART_WORDS).flat().filter((word) => text.includes(word));
  if (presentWords.length === 0) return text;
  presentWords.forEach((word) => {
    text = text.split(word).join(toWord);
  });
  return text;
}
```

- 只替换正文里**实际出现过**的部位词：混合正文（上衣+连衣裙）切"连衣裙"→全部归一为"连衣裙"；偶然提及的"鞋子不动"不会被误伤（since 鞋子不在 presentWords 除非出现）。
- 用户手动改过一处词导致状态与正文错位时，切一次部位即整体对齐。
- `selectRecolorPart` **去掉早退** `if (part === recolorPart) return;`：保证任何切换都实时重算联动（例：正文 4 处"连衣裙"，切"上衣"→4 处全变"上衣"；再切"下装"→全变"下装"）。
- 不动 `recolorPart` 设置项本身（仍随部位单选更新）、不动 `defaultSettings` 的 `recolorPart: "upper"`、不动 `GARMENT_RECOLOR_DEFAULT_PROMPT`。

## 4. 留档（统筹写入，执行方知悉）

- **裁决链**：用户服装改色页 = custom 页（V110 改名保留 + recolor→custom 改向，保证改名后功能不丢）→ V111 已加「更换部位」行 + 类别词联动 + 通用改色提示词框 + 拖拽手柄修复 → 本单在其上补「上装层级」行（仅上装可见、仅记录不写提示词，复用换装控件避免造新视觉词汇）+ 修复"4 处部位词不整体联动"的痛点（重写 `replaceRecolorPartWords` 忽略 fromPart、只换正文实际出现的词；`selectRecolorPart` 去早退保证实时同步）。
- **UI 标签 vs 提示词词**：上装层级 chip label 来自 `UPPER_LAYER_OPTIONS`（与换装一致），提示词里换词来自 `RECOLOR_PART_WORDS`（upper→上衣/上装）；两套词分别维护，本单不改提示词词映射。
- **上装层级"只记录"的设计取舍**：用户只说"加上去"，没说"联动改写提示词"；且 V111 已建立"类别词联动改写提示词"的机制（部位词），上装层级是更细的穿搭结构描述，强行改写会破坏用户手写的精细提示词——故仅记录、不自动改写（若产品后续要"上装层级也进提示词"，再开单）。
- **提示词联动根因留档**：旧 `replaceRecolorPartWords(prompt, fromPart, toPart)` 只替换 `fromPart` 的词 + `selectRecolorPart` 的 `if (part===recolorPart) return` 早退 → 用户手动改过一处词导致状态与正文错位后，切换部位时其余处的词不跟着换（用户实测"改一个其他还要再输入"）。改为"忽略 fromPart + 只换正文实际出现的词 + 去掉早退"后，任何切换都整体对齐，且无 fromPart 概念后彻底消除状态/正文错位问题。
- 用户本次两条诉求对案总表（V112）：①上装层级行（仅上装可见、空一格、仅记录）= §1.1–§1.3；②提示词 4 处部位词整体联动（忽略 fromPart + 去早退）= §1.4。
