# 批量分区功能地图

这份文档对应截图里的批量 tab。结论：每个业务分区应该独立维护，但共用 API、KEY、上传、结果卡、保存目录和基础样式。

## 截图 tab 分区

| tab | 属于哪里 | 是否单独分区 |
| --- | --- | --- |
| 换装（旧名：批量换装） | `src/features/outfit/workflows/outfit/` | 是 |
| 改色（V110 起承接原「批量改色」，recolor 已退役） | `src/features/outfit/workflows/custom/` | 是（custom 页承载） |
| 精修（旧名：批量白底图精修） | `src/features/outfit/workflows/white-refine/` | 是 |
| 批量姿态 | `src/features/outfit/workflows/pose-remix/` | 是 |
| 批量换脸 | `src/features/outfit/workflows/face-swap/` | 是 |
| 固定背景 | `src/features/outfit/workflows/background-change/` | 是 |
| 设计稿 | `src/features/outfit/workflows/design-draft/` | 是 |

> 默认 seed `outfit-pages` 为 **7 页**（换装 / 改色 / 精修 / 批量姿态 / 批量换脸 / 固定背景 / 设计稿，见 `seed/manifest.json` 的 `outfit-pages` 段）。功能页 tab 由 `src/features/outfit/panels/OutfitPageRow.jsx:42` 的 `outfitPages.map` **全量渲染、用户态可增删**（`jingyin-outfit-workflow-pages-v1`），**实际显示页数以 Owner 浏览器当前状态为准，文档不得写死「6 页」**。
> 以下两类**不在默认 7 页内**：①「词」（`src/features/prompt-library/`）是提示词库，**不是生图 workflow tab**；②「随机背景」已通过 `outfit-deleted-modes` 移除（历史/隐藏，不播种）。「批量改色」已于 V110/V113 退役，并入「改色（custom）」。

额外已有或隐藏分区：

```text
src/features/outfit/workflows/outpaint/      （历史/隐藏，已不播种）
src/features/outfit/workflows/local-detail/
src/features/outfit/workflows/custom/
```

## 当前代码入口

目前所有批量 workflow 的实际 JSX、状态、任务构建仍在：

```text

```

不要一次性把它全部拆空。以后每次只迁一个 workflow，迁完运行检查和构建。

## 修改某个分区时怎么发给 Codex

示例：只改随机背景。

```text
docs/V11维护文档/00-总索引.md
docs/V11维护文档/05-批量分区功能地图.md
src/features/outfit/workflows/random-background/README.md
prompts/README.md
```

如果涉及 API，再加：

```text
docs/V11维护文档/04-API调用与登录系统地图.md
src/api/outfit.js
```

如果涉及重复 UI，再加：

```text
docs/V11维护文档/02-重复功能同步登记表.md
src/shared/ui/README.md
```

## 当前重点问题定位

| 问题 | 优先发送文件 |
| --- | --- |
| 批量白底精修色差、牛仔提蓝、图钉/夹子/衣架、褶皱整理 | `src/features/outfit/workflows/white-refine/README.md`、`src/outfit-workflow.jsx`（`WHITE_REFINE_DEFAULT_PROMPT`） |
| 随机背景偏暖、亮度不统一、人物硬抠边贴图感 | `src/features/outfit/workflows/random-background/README.md`、`src/outfit-workflow.jsx`（`RANDOM_BACKGROUND_DEFAULT_PROMPT`） |

> 2026-09-26 起后端不再追加任何 SKILL / 规则（只发用户原话），上面两类问题只能通过默认提示词或用户自己写的提示词解决。注：「随机背景」已通过 `outfit-deleted-modes` 移除（见上表说明），非默认页，上面第二条仅作历史口径留存。

只改这类问题时，不需要把整个项目或全部历史大文件发过来；先发对应 workflow 的 README、维护地图和相关提示词/API 文件即可。
