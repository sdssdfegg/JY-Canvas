## 4. 接入顺序
1. **先核心 Skill**：商品理解、营销策划、详情叙事、视觉导演——正文交付一批接一批；
2. **再条件专项 Skill**：文案策划、人物与使用场景、产品专项表达、详情质量审查；
3. 每批只处理已交付的正文，未交付的不动、不猜、不代写。

## 5. 每次接入的交付四件套（强制）
每接入一份正文，必须提供：
1. **修改差异**：改了哪个 SKILL.md 的哪些段落，旧→新对照（保留项一并说明）；
2. **实际运行读取证据**：证明运行时真读到新正文（如注册表/注入/读取探针），不是纸面改文件；
3. **触发测试**：正式条件成立→触发；不成立/仅旧键→不触发（含防误触发）；
4. **提示词污染测试**：新正文未被全文注入生图提示词、未触发的能力未进入、内部审计未污染。
