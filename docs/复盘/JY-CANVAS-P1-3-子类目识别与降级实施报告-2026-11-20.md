## 三、置信度真实消费（约束3，核心）
新增 `applyConfidenceToRules(skill, resolution, config)`——**置信度决定运行时加载哪一层专业规则，不是只记录**：
| 置信度 | 加载层（level） | 实际效果 |
|---|---|---|
| high | `full_pack_rules` | 加载完整有效包（含继承字段、子专属 analyzeAttributes/coverage） |
| medium（多包同分/子类目不确定） | `parent_common_rules` | **不启用任何行业专属策略**——用通用公共底座 + 父行业 coverage；`industrySuppressed=true`，子专属属性被抑制 |
| low / 循环 / generic | `generic_rules` | 只加载公共底座，不加载任何行业专属规则 |

接入点：`applyIndustryResolution` 用返回的 `rules` 作为下游所有规则消费点（analyzeAttributes/taboos/coverage/sellingAngles/outputRequirements）的实际来源；medium/low 时不加载行业专属 coverage 与 outputRequirements（`suppressed_by_confidence`）。**运行时证据**：AM7 用真实 buildDetailPromptGroup 验证"版型和口红"（多包同分 medium）的 `v2Control.ruleLoadDecision.level=parent_common_rules`，非仅审计字段。

## 四、分级降级链（约束4）
- 子类目不确定（medium）→ 降父行业公共规则（parent_common_rules）。
- 行业也不确定（low/generic_fallback）→ generic 公共底座（generic_rules）。
- 继承循环 → generic（cycleDetected=true）。
- 实测四级对照：high=full_pack_rules、medium=parent_common_rules、low/generic=generic_rules、循环=generic_rules。
