## 二、五项执行约束逐条落实
1. **旧词表降为受控 fallback**：`resolveIndustryDecision` 仅在包体系（cleaning 覆盖 + 通用正信号）全部无命中时，才调 `getIndustrySkillByText`，标 `fallbackStatus=legacy_fallback / ruleSource=legacyKeywords / confidence=low`。旧词表不再是并行主判断（AH3/AH11）。
2. **优先级与置信度降级**：唯一主链 `pack_strong_override > pack_signal_match > legacy_keyword_fallback > generic_fallback`；多包正信号同分→`confidence=medium` + `tiedPacks` 记录（AH12 实测验证）。
3. **cleaning 识别保留 + 回归**：cleaning 仍走原强特征覆盖层，`detectIndustryOverride` 独立保留（AH1/AH7）；"包装/羽绒服"不误判服装回归通过（AH13）。
4. **运行时六要素输出**：`industryResolution` 含 `industryId / packId / confidence / evidence / fallbackStatus / ruleSource`，在 `analysis.industryResolution` 与 `v2Control.industryResolution` 双点输出（AH5/AH8/AH9）。
5. **单项单 commit + 全套门禁 + 证据**：本项单独 commit；门禁与证据见第六节。

## 三、单一决策链设计
```
输入文本 + 模型行业提示(aiHint)
  │
  ├─① cleaning 强特征覆盖（detectIndustryOverride，含服装强特征否决）
  │     → packId=cleaning, confidence=high, path=pack_strong_override
  ├─② 行业包通用正信号匹配（遍历所有 pack.positiveSignals，negatives 否决，弱语境词不计入）
  │     → 唯一最高分: high / 同分: medium+tiedPacks, path=pack_signal_match
  ├─③ 旧词表受控 fallback（仅前两步无命中）
  │     → fallbackStatus=legacy_fallback, confidence=low, path=legacy_keyword_fallback
  └─④ generic 末级降级
        → fallbackStatus=generic_fallback, evidence.via=no_pack_no_keyword_match
```
