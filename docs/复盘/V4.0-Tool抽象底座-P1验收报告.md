## 一、目标与范围

V207 结论「对现有架构进行较大改造」：保留被反复验证健康的确定性执行内核（任务状态机 / 幂等键 / 重试退避 / 全局 5 并发 / 启动恢复），改造上层智能执行抽象。P1 是 P3/P4/P5/P7/P8 的**共同前置**，且为**纯增量包装**、风险最低、回滚最简单。

本单范围（严格照 V207-04 P1，不扩）：把出图 / 编辑 / 资产 / 任务 / 版本封装为标准化 Tool，落地轻量注册表 + 7 个 Tool 适配器 + 一个只读发现端点 + parity 门禁。**不改任何既有调用点**（P5 才切换），不碰出图主链路。

不在本单（明确排除）：阶段 6 整体预览 / 长图 / 导出（顺延 V209）；V206 两处功能 P0（另单）；P2–P8 各阶段；Skill 注册表（P2）/ Context 回灌（P4）/ Agent 决策（P5）/ 质检补强（P6）/ 画布链路（P7）/ 换装声明化（P8）。
