## 一、目标与范围

V209 = **把已经建好的详情创作主流程打通**，不新增功能。详情创作 B1 分析 → B2 导演 → B3 编译/冻结 → B4 质检 → 阶段 4 批量生成的整条链路上，存在四处参数链断点，导致「策划能出、出图不通」：

1. **A/B 冻结键空间不一致**：`compile-screen.js` 写 `frozenPrompts[screen.id]`（`screen_N`），`buildBatchSpec` 读数字索引 `frozenMap[i]` → 批量生成直接抛「没有可生成的屏」，主流程硬阻断。
2. **参考图未进出图请求**：`buildTaskRecord` 未接收 `referenceImagePaths` → 出图请求不带参考图。
3. **用户选的推理模型不生效**：前端 hook 只传 `{ apiKey }`，`textModel` 到不了服务端。
4. **行业宣传边界未进质检**：`qc-review.js` 未把 `industryStrategy` 传进质检提示词，`promoBoundaries` 只进导演、不进独立质检。

本单范围（严格照执行单 §6 四条硬约束，不扩）：只修这四处断点。不做阶段 6 整体预览/长图/导出、不做 P2–P8 架构改造、不新增 11 个 `TRACED_OPTION_KEYS` 结构化录入 UI（V206 报告列 P1，另单）、不改前端布局与视觉、不重写策划链路。

不在本单（明确排除）：阶段 6（顺延 V210）、V206 两处功能 P0（另单）、P2–P8 各阶段、11 选项结构化录入、真实出图（无 KEY）。
