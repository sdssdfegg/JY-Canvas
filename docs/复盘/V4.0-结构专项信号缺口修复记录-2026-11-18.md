## 0. 核实：specialty_condition_met 实际语义与依赖（裁决第5步）
| 项 | 核实结果 |
|---|---|
| 聚合 activation 键 | `product-specialty-expression` 契约 `activation_conditions=["specialty_condition_met"]`（六类专项共用单一聚合键） |
| required 键 | `required_context=["specialty_evidence"]`（结构事实与效果证据共用） |
| condition 唯一来源 | 归一化表 `reliable_effect_evidence → specialty_condition_met`（效果证据语义，裁决禁止挪作结构触发） |
| evidence 来源 | `effect_evidence → specialty_evidence`（效果）+ `confirmed_structure_fact → specialty_evidence`（结构） |
| 其余五类依赖 | 成分/对比/材质/用法/效果在引擎层无独立触发键，均由六类聚合契约 + SKILL 07 正文 six_specialties 描述；改聚合键来源不影响其正文定义 |

**最小兼容方案**：新增独立结构任务信号 `structure_task_required → specialty_condition_met`（与效果路径共用聚合键、语义互不冒充），结构事实 `confirmed_structure_fact → specialty_evidence` 不变。改的是"触发条件键的来源之一"，不动聚合契约本身、不动其他五类。
