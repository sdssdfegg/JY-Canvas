### 1.1 【最重要】`buildTasks`（73 行）与 `modelForIndex`（5 行）**不是 indent=0，是组件内部函数**

⇒ **这是支持"新建 `src/features/outfit/` 专用模块"的核心论据**（详见 §5.3）。
