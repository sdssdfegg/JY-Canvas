## 6. 拆分方案与净省预估

### 落点（不触发停手条件 #2）

- **推荐落点**：在既有文件 **`src/shared/local-edit-mask.js`** 末尾追加 `export function createLocalEditInteraction(deps)`。
  - 理由：该文件已是局部编辑共享枢纽（导出 mask 常量、`maskBoundsFromCanvas`/`expandMaskBoundsToCropRect`/`canvasToPngDataUrl`/`normalizeMaskCanvas`/`createLocalEditAlphaMask` 等），工厂所需 helper 大多已在作用域内；几何类 `fitRectToRatioLocked`/`snapSizeToRatio`/`sharedConstrainCropRect` 同目录 `local-edit-geometry.js` 兄弟 import 即可。
  - **追加既有文件 ⇒ `fileCount` 不变 ⇒ 不触发 019 扫描漂移、不需划账**（MEMORY §7「同域第二批追加进既有文件」）；故**不命中停手条件 #2**。
- ⚠️ 备选：若统筹坚持新建 `src/features/local-edit/interaction.js`，则命中**停手条件 #2**，需先裁决开新文件 + 019 划账后再派施工单。本设计不推荐此路。

### 净省口径

`净省 = (main 侧删除行 + outfit 侧删除行) − 工厂行 − 两侧薄壳行`。薄壳按 `xxxDeps` 对象压成 1 行 + `createLocalEditInteraction(deps)` 调用 1 行计（每侧 2 行，共 4 行）。工厂行 = 单份共享体 + 解构/return 样板(~15 行)。**最终数字以 `git show <commit>:file | wc -l` 实测为准（MEMORY §8），下表为按函数实测行数的估算**。

### 拆成 3 单（线 B，不混线 A；一单一 commit）

## 7. 后续施工单的冒烟要点（普通裁剪 / 局部回贴 / 涂抹蒙版）

三条链路即本区域业务语义分歧所在：`isLocalMode` 守卫区分普通裁剪与局部编辑，`isMaskMode` 区分框选(rect)与涂抹(mask)。

### 7.1 普通裁剪（仅 main，`!isLocalMode`）
- 打开弹窗：默认选框 = **图片自身比例居中 62%**（`defaultQuickLocalEditCrop`，1450-1464），**不是正方形**；点比例按钮才整形。
- 拖拽/缩放手柄：`updateCropRect` 中 `ratioLocked = isLocalMode && !isMaskMode = false` ⇒ **不吸附比例**，选框可自由比例（`constrainCropRect` 仅夹边界）。
- `fitRectToRatio`：`ratioLocked=false` ⇒ 走自由矩形算法（1855-1883），非锁定。
- 应用：`cropLocalEditFile(item, cropRect, "crop", { fallbackToItem: true })`（2076）；输出尺寸恒等于选框原图像素尺寸。
- 回归点：比例按钮 → `chooseLocalRatio` 在普通裁剪下应**不触发**（守卫 `!isLocalMode` 拦截）。

### 7.2 局部回贴 / 框选（isLocalMode，rect 模式，`!isMaskMode`）
- 打开弹窗（main）：默认选框 = 当前选定比例居中 62%（`ratioLocked` 真 ⇒ `fitRectToRatioLocked`）；outfit：`defaultLocalEditCrop` = `fitRectToRatioLocked(selectedRatio)`。
- 改比例：`chooseLocalRatio`/`chooseRatio` → `fitRectToRatio(current, nextRatio)`，`ratioLocked` 真 ⇒ **吸附比例**。
- 拖拽：`updateCropRect` `lockRatio` 真 ⇒ `snapSizeToRatio` 吸附 + `sharedConstrainCropRect` 夹边界。
- 旧会话 `cropRect` 回贴：`onImageLoad` 按 `ratioLocked` 重新整形（中心不动），避免"头部显示 2:3、选框却是别比例"。
- 应用：main `cropLocalEditFile(item, cropRect, "local_edit", { fallbackToItem: true })`；outfit `cropLocalEditFile(item, cropRect, "local_edit")`（无第四参）。
- 回归点：两巨石的回贴选框比例必须与当前选定比例一致；尺寸=选框像素尺寸。

### 7.3 涂抹蒙版（isMaskMode）
- 进入：组件切 `LOCAL_EDIT_MASK_MODE` ⇒ `chooseEditMode` 算 `maskBounds` → `setCropRect(expandMaskBoundsToCropRect)`。
- 画笔：`begin`/`move`/`endMaskPaint` → `paintMask`（canvas 2d，`source-over`/`destination-out` 橡皮）；`sourceBrushSize` 按显示/原图缩放；右键拖拽改笔刷（`brushResizeRef`）。
- 键盘 `[` `]`：`changeBrushByKeyboard`（effect#3）改 `brushSize`（step 4 / Shift 12）。
- 涂抹后：`refreshMaskState` → `maskBounds` → `setCropRect`+`setMaskPainted`+`setMaskRevision`。
- 应用：`cropLocalEditFile(item, maskCropRect, "mask_edit", { fallbackToItem: true })`（main）/ `"mask_edit"`（outfit）→ `onApply` 带 `maskDataUrl`(`canvasToPngDataUrl`)+`maskBounds`+`brushSize`+`maskOpacity`。
- 清除：`clearMask` → `setMaskPainted(false)`+`setMaskRevision+1`。
- 切图/卸载：effect#4 守卫——main 有 `!isLocalMode`（普通裁剪不进此 effect），outfit 无；验证**切图后蒙版不串图、对已卸载组件 setState 不报警告**（`cancelled` 守卫 1797/4906 必须保留）。
