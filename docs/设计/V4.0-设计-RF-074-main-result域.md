- **注 ① `removeDetailResultIds`**：语义确属 detail（改的是 `detailGroups.prompts[].results`），但**唯一调用方是 `deleteSelected` / `deleteResult`**（全仓 grep 命中 3 处 = 定义 + 这 2 处调用）。⇒ 建议**随 delete 族搬走并作为工厂内部函数（不进 `return`、不在调用点解构）**，零跨工厂成本。若统筹坚持"严格按域归属"，则留在 main 并由 delete 族注入（+1 注入项，A −9）。**两种都对，A 差 9 行，不影响结论。**

- **注 ③ `refreshHistory` / `syncHistoryFromServer`**：语义属 history 域（IndexedDB 读取），但 `refreshHistory` 与 `clearSelection` **内部互调**。⇒ 建议在 **result 工厂内**作为内部互调搬走（零跨工厂）；若统筹判 history 域须独立 ⇒ 留 main，A −12，**不影响结论**（195 → 183 仍 ≥ 100）。
