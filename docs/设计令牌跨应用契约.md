## 1. 契约定位与边界

`src/styles/tokens.css` 是**跨应用契约文件**，遵循规划稿 §5.9「面向未来模块：跨应用令牌契约（G9）」四条原始规定：

1. **只含 CSS 自定义属性** —— 不依赖 React、不 `import` 任何项目模块、不含 `@import` / `url()` / JS `import` 语句。独立子应用可直接 `<link rel="stylesheet" href="tokens.css">` 或整文件复制。
2. **组件配方表以「文档 + CSS 类名约定」存在**（见 §5），不写进令牌文件。
3. 新模块验收加一条硬指标：**「视觉 CSS 0 行 + 只消费令牌」**（见 §8）。
4. **主题固定为单主题 dark（见 §4），不再做 `data-theme` 切换**。

**边界（必须守住）**：

- `tokens.css` 是**契约源**，不是样式实现层。主应用真实的字体 / 底色 / 基础重置仍在 `src/styles.css`（V186 把 `:root` 的 5 行基础声明从 `tokens.css` 迁到 `styles.css` 的 `@import` 之后）。
- 独立子应用**必须先加载 `tokens.css`**，再消费 `var(--token)`；`src/shared/ui/ui.css` 里的 33 处 `var(--token, #fallback)` 回退值只是**容错**（见 §6），不应作为令牌来源。
- `src/outfit-workflow.css` 顶部的 **V69 别名映射块（134 处别名）** 是主应用内部历史兼容层，**独立子应用不得复制**（见 §6）。
  - 本契约**不收敛、不新增任何硬编码色值**：V185 已把全仓 216 处 hex（T1-b2 删 3 套主题块后降至 159）固化为永久排除清单（规范 §11.2），T1-b3 切片序列已收官，本文件不重开任何 hex 收敛。
  - **§10 为布局契约扩展节（V190 · T4-a）**：仅补充 Workspace Frame 三段语义与量测口径，**不改变颜色 / 令牌契约**（§2–§3 取值表、§8 判据、159 处 hex 基线逐字不动；216→159 是 T1-b2 删主题块带来的下降，非重开 hex 收敛）。

## 4. data-theme 同步协议

> 主题已收敛为**单主题 dark**：`tokens.css` 仅保留 `:root` 一块，不再写 `data-theme` 切换（规划稿 G9 ④ 原「写 data-theme」条款在 T1-b2 后已无切换对象）。

- **主应用**：主题已固定为单主题 dark，不再设置 `data-theme`（恒为 `:root` = dark）。换装 / 设置页的 `themeOptions` / `THEME_OPTIONS` 仅剩 `dark` 一项，选中态恒真。
- **独立子应用**：单主题下无需监听 `<html data-theme>`（已无切换）。子应用只需加载 `tokens.css`，用 `var(--token)` 消费，恒为 dark 令牌值。
- **新增主题（可推翻路径）**：须在 `tokens.css` 新增 `:root[data-theme="xxx"]` 块并**补齐全部 23 个颜色语义令牌**（键集合必须与 `:root` 逐字一致，否则 `theme-token-parity-check` 判红），同时在本契约 §2 表格追加一列；须 Owner 明确点头另开单。
- **令牌值变更**：只能改令牌值，不能改键集合语义；改后必须同步本契约 §2 / §3 表格，且不得引发 V185 §11.2 永久排除清单之外的 hex 新增。

## 7. 子应用消费示例

### 7.1 路径 A：`<link>` 直接引用（推荐，零复制、随主应用同步）

```html
<!-- 在子应用 <head> 中先引令牌，再引自身样式 -->
<link rel="stylesheet" href="/src/styles/tokens.css" />
<link rel="stylesheet" href="/your-app/app.css" />
```

```css
/* your-app/app.css —— 只消费令牌，不写 hex */
.card {
  background: var(--panel);
  color: var(--text);
  border: 1px solid var(--border);
  border-radius: var(--radius-md);
  padding: var(--space-4);
}
```

### 7.2 路径 B：整文件复制（适合完全独立的仓库 / 构建产物）

把 `src/styles/tokens.css` 原样复制到子应用静态目录（如 `vendor/tokens.css`），`<link>` 或 `@import` 引用。**复制后必须保持文件「只含自定义属性」**（受 `token-contract-check.mjs` 守护），不要顺手加样式规则。

```css
/* vendor/tokens.css —— 逐字复制，不增删任何声明 */
@import "./vendor/tokens.css"; /* 注意：tokens.css 自身不含 @import，此行为引用方写法示例 */
```

> 两条路径的共通前提：单主题下**子应用恒为 dark**（见 §4），无需设置 `data-theme`；子应用自身不要另起主题状态。

## 8. 「视觉 CSS 0 行」验收判据与反例

> 这是新模块 / 新页面验收的硬指标（规范 §5 / §7.2 路线表）：**视觉 CSS 0 行 + 只消费令牌**。

- **判据**：新增的视觉样式文件（如 `feature-xxx.css` / `app.css`）**不得出现任何硬编码颜色字面量**（`#hex` / `rgba()` / `color-mix()` 内联新色），所有颜色 / 尺寸 / 圆角 / 间距 / 阴影一律走 `var(--token)`；令牌本身只允许来自 `tokens.css`（或其回退值容错）。
- **正例**（通过）：

```css
.btn {
  background: var(--accent);
  color: var(--accent-on);
  border-radius: var(--radius-md);
  padding: var(--space-3) var(--space-4);
}
```

- **正例（V187 · ResultCard 外壳契约，通过）**：`.ui-result-card` 仅消费令牌（`background: var(--panel)` / `border: 1px solid var(--border)` / `box-shadow: var(--shadow)` / `border-radius: 8px` / `aspect-ratio: 3 / 4`），`:hover` 用 `color-mix(in srgb, var(--accent) 45%, var(--border))` 仍是令牌混色、零新增 hex；与快捷 `styles.css .assetCard`、换装 `.outfitWorkflowEmbedded .assetCard` 外观逐字一致，属「视觉 CSS 0 行 + 只消费令牌」规范示例。
