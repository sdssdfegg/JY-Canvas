# Skill 04 · 视觉导演与画面创意规划（visual-art-direction）

> **正式专业正文 V1.0**（SKILL 04，核心必需能力，执行模式 Mandatory，权威来源：正式 Skill 契约）。接入日期 2026-11-18，来源 ChatGPT 交付。
> 职责：根据商品事实、营销策划结果、详情叙事规划及用户视觉要求，为每一屏制定具体、合理、有表现力的视觉创意方案，并把内容任务转化为可执行的画面设计指令。本 Skill 是整套详情的视觉创意与设计决策中心，不是画面描述器，也不是固定模板生成器。
> 兼容保留：文件身份/路径/接口/Schema/注册关系/marker（`JINGYIN_DETAIL_V2_SKILL_VISUAL_ART_DIRECTION`）不变；旧有价值规则合并保留。**门禁回链 phrase「禁止仅背景/颜色变化」逐字保留，不得简写。**

## 职责
为每一屏制定具体、合理、有表现力的视觉创意方案，将内容任务转化为可执行的画面设计指令。核心目标：每一屏既准确表达内容，又具备明确的视觉概念、合理的画面逻辑、恰当的场景设计、清晰的信息层级和足够的视觉吸引力。禁止把所有详情做成同一种构图、同一种背景、同一种摆放方式，只替换商品名称和卖点文案。

（兼容保留旧职责：制定整组视觉 DNA 与每屏构图/镜头/光影/场景/主体位置/表达类型的六维实质差异；视觉服务内容；根治"两屏只换背景冒充差异"与"全局规则每屏复制导致提示词过长"。）

## 触发
**必需启动（正式 §2.1）**：新建一套详情 / 整套重新规划 / 新增详情屏 / 修改某屏视觉创意 / 修改某屏画面构图场景视觉风格或元素关系 / 用户要求调整整套视觉方向 / 用户要求解决画面单调、缺乏设计感、场景不合理、构图重复。**不得因商品事实不完整、叙事规划不完整、上下文为空或用户没提供视觉参考图而取消启动**；信息不足时基于可确认内容保守设计，不靠编造商品属性补画面。

**可复用（§2.2）**：纯文字修改、无视觉影响的内容调整可复用有效视觉方案；内容任务/商品主体/视觉目标/用户要求变化则必须重新评估。

（兼容保留旧触发：每次策划必经、在叙事之后文案之前；整组生图尤其防"三屏雷同"与"全局规则重复占 2/3 篇幅"。）

## 输入
（正式 §三）可用：1 商品理解与事实档案；2 营销策划结果；3 详情叙事与屏级内容任务；4 商品参考图；5 商品包装标签外观及已有素材；6 用户指定视觉风格；7 用户提供参考图及明确要求；8 整套已有视觉方案；9 当前屏及相邻屏必要视觉上下文；10 当前项目可用图像生成能力与约束。输入须区分：已确认事实 / 可观察视觉特征 / 用户明确要求 / 设计创意 / 尚未确认信息。**设计创意可自由发挥但不能伪装成商品事实。**

（兼容保留：`planning.screenRoles`、`screens`、`product.styleDirection`、`industryProfile`、平台视觉规范；现有构图变体资产 `composition-variants.js` 9 模块×4 变体、`V1_LIGHT_LINE` 全屏恒定视觉基线（v1 默认不生效、可复用资产）。）

## 判断方法
**基本工作原则（正式 §四）**：4.1 先理解内容再决定画面——视觉方案由本屏内容任务决定，不得先套常见构图再塞卖点；设计前明确：本屏真正表达什么、消费者需看到什么才理解、哪些必须画面表达/哪些适合文字/哪些需产品主体直接呈现、是否需场景人物道具环境视觉辅助、哪种画面方式最适合。画面服务内容不让内容迁就模板。4.2 设计必须有具体创意——禁把"产品居中展示/背景简洁大气/标题突出/卖点清晰/高级感十足/视觉冲击力强/产品与背景融合/科技感元素/画面干净有质感"当完整方案（可作辅助但不能替代）；每屏至少说清 7 点：画面主要表现什么、产品主体如何参与、场景为何存在、主要视觉元素、元素关系、如何表达本屏核心内容、视觉重点落点——只看描述仍无法想象具体画面即创意不完整。4.3 不追求无意义复杂——禁为专业感任意加无关装饰物/无意义科技线条/不相关光效/过量悬浮物/随机几何图形/无关道具/无叙事作用的背景元素/纯填画面装饰；每重要元素须有存在理由，复杂度匹配任务与信息密度。

**视觉概念与创意方向（§五）**：5.1 每屏先定视觉概念（创意核心，非风格名或场景名词——"清洁剂实验室风格"只是风格，"以透明水流穿过污渍区域的瞬间表现清洁过程中的作用关系"才是概念；"服装展示"是类别，"以真实穿着状态展示衣服在日常动作中的垂坠与轮廓变化"才是概念）；概念须解释为何这张图要这样设计而非随便换背景也成立。5.2 方向由商品与任务决定（写实商业摄影/C4D三维/创意静物/真实生活场景/使用场景/概念化视觉/材质质感/组合陈列/图文信息设计/前后对比/人物互动/其他——可用方式非必执行风格，不得某风格当所有商品默认、不得日化强制实验室或服装强制模特）。5.3 允许创意表达但须有逻辑（艺术化/概念化/三维化/隐喻可行，但不改商品真实身份、不虚构功效、不制造未确认效果、不把装饰隐喻当真实实验、不暗示未确认能力、不让创意抢主体地位——创意可超越真实场景但不能超越商品事实边界）。

（兼容保留旧方法：整组 DNA 定一次（色调/材质质感/光线风格/镜头语言/画面比例/品牌调性）只在整组层声明；每屏六维差异（构图/主体位置/镜头/场景/光影/表达类型）逐屏比较至少多维实质区别；差异来自内容任务不同非换纯色背景；变体耗尽按规则重规划而非复制已用变体（工程可复用 `variantFor`）。）

## 规则
（正式 §六~§十三 + 旧规则合并）
1. **场景设计与元素关系（§六）**：场景是否有由表达任务决定；需要时明确场景类型、与商品/消费者需求关系、必须出现与辅助元素、空间环境逻辑、产品如何自然融入；禁为丰富随意加客厅厨房浴室卧室户外等场景、禁商品与环境无关拼接。元素关系检查：产品与道具空间关系、人物与商品真实使用/展示关系、道具符合场景、前中背景层次、光影反射符合空间、元素不冲突、商品不被遮挡、无明显物理逻辑错误。场景非每屏必需（组合展示/信息图/概念表达/局部细节/文字图形主导/简洁静物可行），禁为丰富强制每屏加生活场景。
2. **商品主体与产品保护（§七）**：保护参考图真实身份特征（包装形状/瓶体结构/标签位置与主色/外观比例/关键结构/可识别文字/其他识别特征）；禁为美观擅自换包装瓶型标签颜色结构、禁换成相似但不同产品。展示方式按商品形态与任务定（单品/组合/多角度/正侧结合/与使用道具结合/人物手持/人物操作/与环境结合/局部/其他）——不默认每屏只能一个产品、也不强制多个；产品数量角度位置比例展示方式符合画面逻辑。商品主体清晰可识别、标签不被遮挡、不被无关元素挤压、比例符合真实、与背景合理区分、不严重改变包装比例、优先保证商品识别与核心信息表达。
3. **构图与空间（§八）**：构图由本屏信息结构与视觉概念决定（左右/上下/居中/偏置/对角线/前后景/多主体/视觉引导/局部放大/环绕/多区域/其他——非固定模板，禁因方便生成让所有屏同布局）；具体说明主体区域/朝向角度/视觉空间/辅助元素位置/文案区与主体关系/前中背景组织/视觉引导/留白服务阅读，禁"合理排版/构图饱满/画面平衡"等不可执行描述。允许视觉重心变化（产品/场景/人物动作/视觉效果/信息图形/文案/产品与场景共同主导），不强制产品每屏正中、也不故意用不合理构图。
4. **视觉节奏与整套一致（§九）**：整套视觉 DNA 统一（主色与辅助色/字体文字风格/光影质感/视觉语言/图形装饰/产品呈现原则/设计气质）——由商品与用户要求定，是识别基础非所有屏同构图场景。屏级合理变化——检查连续相同构图/角度/背景/场景/人物动作/图文结构/视觉概念，有强化价值可保留否则按内容任务调整。不强制每屏完全不同（可用统一背景体系/相似构图/重复元素建立连贯性）。首屏是重要视觉入口但不得固定产品居中/三卖点/大标题加产品/单一静物/固定左右布局，由商品与营销任务决定；后续屏不因非首屏降低设计质量。
5. **文字与视觉协同（§十）**：文字是画面设计一部分（标题位置与层级/辅助文案阅读顺序/文案与主体空间关系/文字与背景对比/是否独立区域/是否与画面元素联系/信息密度）；禁默认所有屏顶部大标题+下方三卖点+产品中间+底部横幅（可作特例非默认）。文字层级明确（主标题/辅助标题/说明/重点数字短语仅限有事实依据/其他必要），禁堆砌大量文字、禁把内部分析策划说明设计注释当画面文案、未确认参数数据功效承诺不得出现。文字与画面共同表达（文字清楚表达关键信息、画面建立直观认知与感受、二者不矛盾）。
6. **视觉表现与真实性（§十一）**：写实摄影注意光线/透视/道具比例/人物动作/使用方式/材质表现/环境细节/接触关系合理，避免 AI 拼接感悬浮感不合常识组合。C4D/三维须有完整空间关系、元素与商品色调或主题协调、产品融入空间、光影材质比例透视统一、可创意几何与艺术元素、禁空洞渐变背景加一个产品、禁堆无关三维装饰。效果与对比表现必须有事实或用户素材支持、禁夸大效果/编造测试/概念示意伪装真实实验/改变适用对象范围/用不合理画面差异暗示未确认效果。
7. **人物与专项（§十二/§十三）**：人物/手部/使用场景按需使用——本 Skill 判断视觉上是否需人物及其作用，不替代人物专项能力；明确人物作用/完整局部或手部/与商品动作关系/动作真实逻辑/是否遮挡商品/是否抢重点/场景必要性；禁为生活化强制模特人物手持、禁无事实支持时通过人物动作暗示特定用法或适用范围。涉及商品结构/成分原理/功效效果证据/材质/使用方法/前后对比等须遵守条件专项授权，可决定表现方式但不自行认定专项事实（禁虚构内部构造/添加未确认成分/编造原理机制/猜测材质/创造未确认操作步骤），专项未触发或无授权不得自行加入画面。
8. **旧规则合并**：整组 DNA 统一+每屏精简约束（精简约束仍须含行业禁忌与主体锁防分层加载丢失）；六维差异至少多维实质区分、**禁止仅背景/颜色变化**（案例 E，回链 phrase 逐字）；不写死首屏正面居中构图、首屏构图由 hero 任务决定；全局视觉规则整组写一次避免逐屏复制（重复占比 41.8%）；主体/中文标签保真靠文字约束，图像链路（抠图/遮罩/合成）属阶段 E 评估、本批不接图像处理。

## 输出字段
**屏级输出（正式 §14.1，每屏至少 17 项）**：1 屏幕编号；2 当前屏内容任务；3 视觉概念；4 视觉表达方向；5 主体展示方式；6 场景与环境设计；7 核心视觉元素；8 元素之间关系；9 构图与空间布局；10 产品主体位置角度与比例关系；11 文案区域及图文关系；12 色彩与光影方向；13 视觉重点与阅读顺序；14 与整套视觉 DNA 关系；15 与相邻屏视觉节奏关系；16 事实与专项表达边界；17 当前屏最终视觉执行指令。非每屏都必须复杂场景人物道具，但每个适用项须有明确判断。

**整套级（§14.2）**：整体视觉方向 / 视觉 DNA / 主色与辅助色关系 / 字体与图文风格 / 产品主体保护要求 / 光影与质感倾向 / 屏级视觉变化策略 / 需保持一致的元素 / 允许自由变化的元素 / 整套视觉重复检查结果。

**输出要求（§14.3）**：必须提供可执行具体设计信息，不能只输出风格名称/构图名称/场景名称/色彩名称/"高级感科技感氛围感"等抽象形容词，须让下游提示词编译器理解每屏应生成怎样的具体画面。

（兼容保留：`globalVisualDNA.{palette, texture, lighting, cameraLanguage, ratio, tone, integrityLocks[]}`；每屏 `composition`/`negativeConstraints`/可选 `compositionVariantId`（沿用现有 moduleId 变体值域）；差异说明写入 `planning.dedupLog` 供跨屏校验。）

## 边界
**提示词编译与内容隔离（正式 §十六）**：完整分析/创意推导/备选方案/设计判断/质检清单/内部规则不得整体注入最终提示词，编译器只取经确认获准执行的视觉指令。**当前屏按需注入**：商品主体保护要求/本屏视觉概念/表现方向/场景环境/产品展示方式/构图空间关系/关键视觉元素及关系/色彩光影/文案图文布局/必要整套一致性约束/已触发且授权专项视觉指令——不需要的不注入。**禁止污染**：完整 Skill 正文/内部设计推导/备选创意清单/设计审查过程/内部质量评分/其他屏全部设计说明/未触发专项规则全文/无关商品类别视觉要求。提示词表达应具体清楚简洁——优先描述实际需出现的主体场景构图元素关系文字布局，避免同义词堆叠、大量抽象形容词、互相冲突要求，不把内部策划语言写成图像可见文字。

**职责边界（§十五）**：商品理解确认事实——视觉导演不重新认定功效材质成分结构适用对象范围；营销策划负责需求价值卖点优先级表达方向——视觉负责把既定价值转画面、禁为创意创造新卖点；详情叙事负责屏级任务信息层级屏间关系取舍——视觉负责当前屏如何呈现、禁擅改内容目标/加板块/改叙事顺序，内容任务无法画面表达应反馈不私改；文案策划负责具体文案——视觉负责文案位置层级排版协同、禁改已确认核心文案除非用户授权；条件专项负责专业内容边界——视觉负责画面转译不替代事实认定。

（兼容保留旧边界：只做视觉 DNA 与构图决策，不改视觉参数 UI、不新增视觉偏好必填项、不接生图链路、不改 `src/**`；构图变体只消费现有资产不建第二套。）

## 冲突处理
（正式 §十七失败处理 + 旧冲突规则合并）
参考图不足确认包装细节/叙事缺事实/本屏缺视觉方向/创意与事实冲突/场景与使用逻辑不符/元素过多失焦/多屏高度重复/专项未触发/用户要求与既有方案冲突时——**不得直接关闭本 Skill**，应：1 保留商品身份与事实边界；2 优先完成已确认内容任务；3 删除无依据视觉元素；4 选更简单但合理的画面表达；5 避免未确认专项内容；6 调整不合理构图与元素关系；7 必要时反馈上游问题；8 不编造内容维持画面丰富。除非信息确实无法替代否则不阻塞生成。
- （旧）DNA 统一 vs 逐屏差异：统一在风格基因、差异在六维表达，不冲突，差异不破坏 DNA；六维变体耗尽重规划组合不复制已用变体，仍冲突则降低信息密度而非制造雷同屏；精简约束 vs 关键规则不丢：压缩重复文字但行业禁忌/主体锁/事实锁必须保留。

## 测试案例

**最终执行原则（§十九）**：视觉导演不是把商品放进漂亮背景，而是根据商品真实特点、消费者价值和当前屏内容任务，创造一张有明确视觉概念、合理场景逻辑、具体构图设计、信息层级、审美表现力的商业详情画面——不套固定模板、不滥用抽象形容词、不堆装饰、不虚构事实、不强制每屏人物场景特写、不强制每屏不同构图、不把所有屏做成主图、不让产品与环境不合理拼接、不让创意越过内容授权边界。每一屏都应有独立视觉创意价值，同时保持整套合理视觉一致性。
