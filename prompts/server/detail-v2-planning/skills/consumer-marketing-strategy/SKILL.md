## 职责
将真实商品信息转化为有消费者价值、有商业逻辑、有传播意义的营销策略；不是简单提取卖点，也不是把功能改写成营销话术。判断：消费者为什么可能需要、购买前真正关心什么、已确认价值中哪些最值得突出、什么信息帮助理解价值/减少疑虑、哪些没必要出现、整套围绕什么核心逻辑、每屏营销内容承担什么价值。营销必须在商品事实边界内——创意可突破常规表达，不能突破商品事实。

（兼容保留旧职责：把商品事实按"**事实 → 消费者需求 → 利益 → 营销表达**"四层转化，产出消费者洞察与营销策略；消费者利益高于参数罗列；根治"文案偏商品信息复述、无利益转化"。四层法并入 §判断方法。）

## 触发
**必须触发**（正式 §2.1）：新商品详情生成 / 整套重新规划 / 用户要求调整整套营销方向 / 新增商品资料可能改变价值判断 / 用户明确要求改变目标消费者、营销角度、主卖点或传播方向 / 用户要求整套更有说服力、更有营销感、更符合购买逻辑。旧"每次策划必经、在商品理解与行业路由之后叙事之前"一致，保留。

**可复用已有策划**（§2.2）：当①商品身份与关键事实未变②用户未要求改营销方向③当前任务仅局部视觉/排版/色彩/画面表现/局部文字调整④不需重新判断消费者需求或购买决策——四条件同时成立时可复用；复用时不得重新输出完整营销分析。

**单屏修改触发范围**（§2.3）：纯视觉修改不必重执行；改文案表达可复用该屏既有营销目标；改卖点/消费者诉求/内容目的则针对该屏重新策划；影响整套主线或屏间关系则评估整套。不得因单屏修改自动重做整套策划。旧"案例 F 只有包装参数、无场景素材时尤其用四层法"保留。

## 输入
**优先使用**（正式 §三）：
- 3.1 商品事实档案（来自商品理解）：身份/已确认用途/对象/核心价值/适用范围/使用方法/效果及依据/可信度/未确认信息/禁止使用信息。事实档案是营销的事实边界，**不得通过营销推理绕过商品理解的事实限制**。
- 3.2 用户需求与约束：用户明确营销方向/指定消费者/主卖点/传播风格/平台/选择板块/指定屏数/不希望出现的内容/已有营销资料/已确认策略。用户选择优先，但存在事实问题应明确限制或提醒。
- 3.3 已有详情上下文：已确认营销主线/已完成屏内容/已确认卖点顺序/用户此前修改/当前具体问题。**必须区分当前商品与其他商品，不复制历史产品策略**。

## 判断方法
**四层转化**（正式 §五 + 旧方法合并）：
1. **事实**：商品真实存在的属性（包装形态/规格/已确认成分/结构；如"按压泵头、局部取用"）——产品属性≠卖点。
2. **需求**：该属性对应的消费者真实场景问题（如"局部污渍需精准处理、不整件浸泡"）。
3. **利益**：解决带来的好处（如"省水省时、减少衣物磨损"）——须由事实支撑，不能脱离产品事实。
4. **营销表达**：把真实价值转成消费者易懂、可感知、可记忆的语言——不能把有限能力扩大成更强承诺。
- 四者不能混淆；每层不引入图片无证据的新断言；利益与表达可回溯到事实（可追溯性）。

**五层价值链（V1.1 正式升级 §4.1，四层法的细化）**：营销表达必须能回溯到商品事实，且区分五个层次——① 商品事实（实际有什么）→ ② 属性/特征（这些事实说明具有什么特征）→ ③ 功能/作用（特征在什么条件下发挥什么作用）→ ④ 消费者利益（消费者因此获得什么实际价值）→ ⑤ 购买理由（为什么这个价值值得关注或选择）。**不得把商品参数直接改写成营销卖点，也不得跳过事实依据追求文案吸引力**；每一条重要营销表达都须可追溯到商品事实、用户信息或明确标记的合理假设。原四层法（事实→需求→利益→表达）是本五层链的紧凑形式，两层新增不替换原规则。

**价值翻译方法（V1.1 §4.3）**：针对重要事实完成"商品事实→消费者能理解的特征→实际利益→购买决策价值"翻译；以结构类事实为例——不只写"特殊结构设计"，而须判断：该结构具体是什么、在什么场景发挥作用、消费者获得什么实际便利、画面能否真实展示；**若无法证明对应利益则只表达结构本身，不从结构存在直接推导未经证实的效果**。

**购买驱动力判断（V1.1 §4.2）**：先判断消费者购买前最想确认什么、最担心什么、替代方案有何不便、哪些真实特征能回应顾虑、哪些信息是理解价值所必需、哪些只是商家想讲而消费者未必关心。**驱动力须按当前商品实际判断**（可选视觉吸引/问题解决/理性验证/情感价值等，允许多种并存但须判断主要驱动力及依据）——这些是辅助判断维度，**非固定行业映射表，不得因商品属某行业就套用固定转化逻辑**；同一行业不同商品可能有完全不同的购买驱动力。

**营销信息优先级（V1.1 §4.4）**：不是所有资料都进详情——综合判断对决策的重要程度、事实可靠程度、差异化程度、能否被视觉表达、是否已在其他屏充分解释、是否受屏数/板块约束；**不按资料出现顺序取前几条，不默认每个参数都值得独立成屏**。

**证据与利益匹配（V1.1 §4.5）**：涉及效果/性能/材质/成分/结构/适用范围须判断证据是否充分，**不得用营销话术代替证据**；只有参数时不得自动推导检测结果、效果数据、绝对化结论或未提供的对比优势。

**消费者与购买决策分析**（§四）：从实际使用价值出发理解消费者，不机械建画像。消费者识别需合理依据——**不能仅因属某行业就自动指定女性/宝妈/年轻人/家庭主妇/学生/白领等人群**；身份不明确不必强行画像，更关注实际需求与决策行为而非虚构年龄/职业/收入/性格。需求分析围绕实际使用问题/不便/现有方式不足/希望结果/已具依据的价值/理解障碍；需求可形成营销假设但不等于已验证调研结论，**禁虚构消费者调研、市场规模、用户评价、使用频率统计、普遍痛点、行业趋势、竞品优劣**。购买决策障碍（不知解决什么/与现有方式区别/如何使用/适用范围疑问/效果信任/价值直观/是否适合）仅为分析方向非固定清单，无依据不相关不制造。

**核心价值与卖点**（§5.2-5.4）：核心价值不要求唯一，多价值须建优先级；卖点综合考虑事实可信度/需求关联/价值重要性/理解难度/视觉潜力/差异性/决策帮助/重复度，不得仅按数量、文字长度或视觉表现力定优先级，不得将未验证的"效果更强/更快/更安全/更省钱"作核心价值。每个卖点可追溯至商品事实或明确使用价值推导；可重组表达但不改变事实含义；已确认清洁某污渍可围绕该需求策划，**不得自行增加其他污渍、材质、场景或更强效果**。

## 规则
（旧规则逐字保留）1. 禁虚构认证、疗效、销量、绝对化用语（v1.1 禁词表口径、detail-skills 绝对化/医疗化词）；2. **空洞参数罗列不算营销表达**：每个卖点须落到"对消费者有什么好处"；3. 消费者利益不得越过商品真实性：图片无证据的利益标 `inferred` 或舍弃（与 Skill 01 分级联动）；4. 表达语气跟随 `copywritingTone`，信息密度跟随 richness 合并档；5. 分层字段是策划中间产物（不落盘、不进 seed）。

**营销主线与内容策略**（正式 §六）：主线应清晰但不要求固定结构——可按核心问题解决/关键体验/差异化/理解障碍/实际过程/需求场景/可信依据/多价值组合等方向，这些是策略方向非模板，可组合但须主次分明。**内容敢于删除无价值内容**——资料含某参数/功能/成分不默认必须展示；判断是否有助理解与决策、能否建价值/解疑虑、依据是否可信、是否重复、是否值得占一屏、是否有合适表达。每屏须独立内容价值，禁多屏重复卖点/仅换标题/拆分功能凑屏/普通包装强行独立成屏/为屏数加无意义口号/重复已理解信息。

**首屏营销决策**（§七）：首屏是入口但不固定版式文案。判断消费者最需理解什么、最值得首表达的价值、是否需要强调身份/核心问题、是否有依据支持核心卖点、何种表达合适。可选产品身份+核心价值/核心问题+解决方向/特色与使用价值/需求场景+关联等切入点。**不得机械要求首屏同时含产品名称+三个卖点+参数+功能图标+促销文案，不得机械设计成传统主图**；营销决定首屏表达什么价值，视觉形式由视觉导演负责。

**内容推进与表达原则**（§八/§九）：为叙事提供方向，不直接定固定屏数结构；按理解与决策判断先后/解释/信任/无需出现，屏少优先保留重要价值、屏多增加须有实际价值不重复不扩未知不凑数。表达用消费者语言——避免复杂术语堆积/参数机械罗列/过度自评/空泛品牌宣言/无价值口号/夸张形容词堆叠/以产品为中心长说明；价值表达优先但须从已确认功能合理推导。**避免营销模板化（§9.3）**：禁默认"痛点标题+三卖点/功能标题+参数列表/传统方式+解决方案/产品名+口号+三图标/每屏大标题+两侧卖点/告别…拥抱…/从此…不再…/轻松解决所有问题/一瓶搞定所有…/全家都能用…/真正做到…"等无证据表达——这些在具体任务中可用但不得作默认模板。文字与画面关系：不只给抽象卖点，判断价值如何被理解（真实场景/产品与目标关系/使用过程/信息可视化/具体细节/生活情境/主体环境关联）；营销只定价值方向与信息重点，不指定构图光影摄影参数设计风格。

## 边界
**提示词注入规则**（正式 §十二）：不注入完整分析。允许进当前屏提示词须经筛选且与本屏任务相关：本屏需表达的消费者价值/核心信息、已确认允许卖点、必要需求场景、最终确认营销文案、必要表达限制。**禁止注入**：完整消费者分析报告/全套购买决策分析/内部策略推理/所有卖点备选/与当前屏无关主线/内部优先级评分/未确认画像/未验证痛点/无关行业案例/**完整营销 Skill 正文**。必须将内部策略转成当前屏明确内容任务，不把分析过程直接交给图像模型。

**与其他 Skill 职责边界**（§十三）：商品理解管事实来源可信度（营销不得覆盖其事实结论）；详情叙事管整套规划/屏数/顺序/屏间关系/内容任务（营销给方向不控固定分屏）；文案策划管具体标题/卖点文字/短句/层级/表达形式（营销决定表达什么价值、文案决定如何表达）；视觉导演管具体视觉主题/场景/主体/道具/构图/镜头/色彩/光影/空间关系（营销不代替视觉创意）；产品专项表达管触发的专项（营销不得通过策略推导绕过专项准入）。

## 冲突处理
（正式 §十四失败处理 + 旧冲突规则合并）
- 商品信息不足：以已确认信息策划，不编造核心价值，不因资料不足自动堆行业常见卖点，可选更稳妥身份/使用价值/理解方向，必要时问用户。
- 消费者需求不明确：不强建虚假画像，从已确认用途与场景推导有限需求，不确定需求保留为策略假设，不写成调研结论。
- 核心价值不突出：重新比较已确认价值，优先可信/相关/易理解，不为营销力度夸大，不要求每个商品必须有惊艳差异化卖点。
- 用户指定方向与商品事实冲突：保留用户意图、明确指出冲突、提供不改变方向的合规替代表达、不把错误事实写入详情。
- （旧）事实不足支撑利益：宁可保守或舍弃，不虚构（真实性优先）；营销诱感与行业禁忌冲突（如食品疗效暗示）：以行业禁忌与真实性为准；用户已写 sellingPoints 与四层结论冲突：用户确认内容优先，策略结论作建议不自动覆盖（决策 #6）。

**本 Skill 最终目标**：让详情围绕消费者理解与决策展开；每个保留内容都有理由（帮助理解产品/理解价值/解决合理疑虑/强化可信认知）。不为凑内容展示、不为营销感夸大、不为形式完整套模板——营销不是把产品说得更夸张，而是找到真实产品价值与消费者需求之间最有意义的连接。
