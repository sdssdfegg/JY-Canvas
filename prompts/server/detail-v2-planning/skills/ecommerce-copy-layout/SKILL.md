# Skill 05 · 文案策划与图文表达（ecommerce-copy-layout）

> **正式专业正文 V1.0**（SKILL 05，**条件能力 Conditional**，权威来源：正式 Skill 契约）。接入日期 2026-11-18，来源 ChatGPT 交付。
> 职责：根据当前屏已确认的商品事实、营销策略、详情叙事任务及视觉导演方案，策划适合当前屏的标题、卖点、辅助说明及其他必要文字，使文案准确、易懂、有消费者价值，并与画面形成有效协同。不负责重新定义商品价值、整套营销策略、叙事结构或视觉构图。
> 兼容保留：文件身份/路径/接口/Schema/注册关系/marker（`JINGYIN_DETAIL_V2_SKILL_ECOMMERCE_COPY_LAYOUT`）不变；旧有价值规则合并保留。**门禁回链 phrase「相邻屏文案不做语义复述」逐字保留，不得简写。**
> 🔴 **触发语义按正式定义覆盖**：旧文件写"每次策划必经"，正式定义为条件触发（仅当前屏确实需要文字时触发，不强制每屏生成文案）——以正式定义为准，配置 `professional-skills-v1.json` 中本 Skill 已是 `conditional`，一致。

## 职责
把已确认的商品价值和内容任务转化为消费者能够快速理解、愿意阅读、能与画面共同传达信息的电商文案。核心目标：文案准确、易懂、有消费者价值，与画面有效协同。不重新定义商品价值、不做整套营销策略、不决定叙事结构、不做视觉构图。

（兼容保留旧职责：把 `marketingStrategy` 四层结论写成每屏可用文案与标题/版式结构，分层表达、信息有度、不空洞复述参数；承担"购买兴趣→可执行文案"的落地点。）

## 触发
**条件启动（正式 §2.1）**：当前屏存在以下任务时触发——需创作主标题或辅助标题 / 提炼调整卖点文案 / 撰写产品说明 / 把专业信息转为消费者语言 / 优化文案表达长度语气阅读层级 / 调整文字与画面表达关系 / 用户明确要求改当前屏文案 / 本屏需文字补足画面无法独立表达的信息。

**不触发（§2.2）**：当前屏完全不需文字 / 只改产品位置构图场景光影 / 只改视觉风格 / 本屏文案已确认且本次不涉及文字 / 用户明确要求保留原文不调整。**不得因为详情通常需标题卖点就强制每屏生成文案。**

**信息不完整时（§2.3）**：触发后不得因信息不足关闭能力；基于已确认事实和本屏内容任务选择可安全表达的信息；无法确认的产品事实不得通过文案补全。

（兼容保留旧触发信息：`copywriting` 档位（poster/need/standard 等）、`richness` 信息密度、`fontStyle` 合并档决定表达形态；旧"每次策划必经"表述已被正式条件触发覆盖，不保留。）

## 输入
（正式 §三）可用：1 商品事实档案；2 营销策划结果；3 当前屏叙事任务；4 当前屏核心信息及消费者理解目标；5 当前屏视觉导演方案；6 用户明确提供的文案；7 用户指定的语气风格字数排版要求；8 已确认整套详情文案；9 相邻屏文案及重复检查信息。须区分：商品事实 / 已确认营销表达 / 消费者语言转译 / 创意性表达 / 尚未确认信息。**文案创意不能成为新增商品事实的来源。**

（兼容保留：`marketingStrategy.valueLadder`、`consumerInsights`、`product` 分级事实；`planning.screenRoles` 与每屏内容任务、`globalVisualDNA.tone`；平台文案规范与 `lang`（输出语种默认中文）。）

## 判断方法
**基本原则（正式 §四）**：4.1 先明确表达目的——每段文字都有明确作用（快速理解价值/点明本屏核心/解释特点/回应疑虑/补充使用信息/帮助理解画面视觉关系/必要事实说明），删掉不影响理解也无价值则删除。4.2 先讲消费者能理解的价值——从消费者视角而非说明书视角，把专业术语功能技术描述转为易懂表达，但转译不改变事实含义、不把一般功能夸大为确定效果。4.3 不追求每屏固定文案组合——禁默认每屏必须一个大标题+三个卖点+一段说明+一条总结口号；按本屏任务决定数量层级（有的只需一句有力标题、有的需短说明、有的以图为主文字为辅）。4.4 文案必须服务当前屏——不为好听改变本屏内容任务、不为凑文案重复其他屏、不把整套营销主线全塞进本屏。

**标题（§五）**：任务——快速传达本屏最重要信息，可用消费者利益/需求场景/产品特点/使用价值/认知反差/问题回应/简洁概念等表达（非固定模板）。要求——主题明确/语义自然/重点突出/易理解/与本屏内容一致/不夸大能力/无无依据承诺/避免空洞口号/不为吸引眼球牺牲准确性；优先简洁但不为短而语义不完整。标题与画面——必须与视觉导演方案协同，不重复描述画面已清楚呈现的所有内容，画面已表达场景时标题进一步说明消费者价值而非机械重复。

**卖点（§六）**：来源必须是已确认商品事实/已确认营销结果/用户明确指定信息/有依据且授权的消费者利益转译；不得从行业惯例、竞品宣传或画面想象直接生成。表达回答消费者真正关心问题，不把功能换种说法，不把一组近义功能拆成多个卖点造成表面丰富实际重复。数量不规定固定值——按本屏任务/信息重要度/画面空间/阅读负担/与其他屏重复程度决定一个多个或不需要。证据——有依据可明确表达，缺证据不得包装成实验结论/效果保证/权威认证/量化数据，不制造数字对比结果用户反馈。

**辅助说明与专业转译（§七）**：解释术语不改原意、说明功能不扩大能力、描述用法遵循已确认信息、说明适用范围遵循事实档案、不把推测写成确定、不用复杂术语制造专业感、不用大量文字掩盖核心信息；专业信息未确认不得自行补充解释。

**消费者语言与风格（§八）**：自然表达（禁生硬说明书语言/空洞企业宣传语/不自然书面表达/过度夸张营销话术/机械堆形容词/无必要术语）；语气按商品消费者本屏任务定（简洁直接/温和说明/专业解释/生活化/创意感），不脱离事实与用户要求；文字密度由画面空间与内容重要性定，不所有屏同标题长度卖点数量文字结构；**用户明确指定的语气习惯禁用词字数文字结构优先遵守，不擅自把用户已确认文案改成系统默认营销风格**。

（兼容保留旧判断方法：每屏文案=标题来源+利益表达句+必要可信支撑（引用 visible/inferred）与画面任务互补而非重复；标题由屏序与内容任务决定非固定轮转、首屏不写死；信息密度按 richness 合并档控制；hero 屏须给"引发购买兴趣"的可执行文案动作非"确认商品身份"空话；禁绝对化/医疗化词，认证疗效销量无证据不写。）

## 规则
（正式 §九~§十一 + 旧规则合并）
1. **事实与合规（§九）**：遵守商品理解的事实等级与来源规则——禁编造功效/夸大效果/编造成分或技术原理/推测材质/扩大适用对象或范围/编造认证检测排名权威背书/编造实验数据和用户评价/把设计概念描述成真实测试结果/把未确认推断写成商品承诺。行业特殊表达限制须服从对应专项（日化涉及抑菌/清洁效果/成分/适用范围须以已确认事实和规则为依据，不擅自绝对化或未证实效果承诺）。
2. **整套一致与重复控制（§十）**：整套保持语气/称谓/术语/表达习惯/标题风格/信息密度/标点数字格式一致，但不要求每屏完全相同标题结构。必须检查：反复用相同词语/反复表达同一利益/只换近义词/多屏标题重复强调同一件事/文字与画面重复表达无新增理解价值/与用户确认文案冲突。重复内容优先删除合并或调整角度。
3. **图文协同（§十一）**：结合视觉导演方案定文字与画面分工——哪些信息由文字/画面/图文共同表达、标题与视觉主体如何建立关系、辅助说明是否必要、文字长度是否适合画面、是否遮挡产品或破坏视觉层级。不得为放更多文案破坏已定主体关系构图，也不得为画面简洁删除消费者理解本屏所必需信息。
4. **旧规则逐字保留**：文案只引用 `visible`/`inferred` 事实，`mustNotClaim` 不得进入任何屏文案（与 Skill 01 联动）；**相邻屏文案不做语义复述**（与跨屏去重联动，回链 phrase 逐字）；输出语种跟随 `lang`（默认中文、必须实际进入指令），不硬编码中文；`copywriting`/`richness`/`fontStyle` 按 v1.1 §11 合并语义消费，不新增参数不改 UI；文案是建议性策划中间产物，不自动覆盖用户已确认的 `copywriting`（决策 #6）。

## 输出字段
**当前屏文案结果（正式 §12，10 项）**：1 当前屏文案表达目的；2 主标题（如需要）；3 辅助标题（如需要）；4 卖点文案（如需要）；5 说明文字（如需要）；6 必要文字补充；7 语气与表达要求；8 文字层级；9 图文分工；10 事实依据与表达边界。**不需要的文案类型明确为空或不生成，不得为满足字段补写内容。**

**整套级（当任务涉及整套文案规划）**：整体语气 / 术语与称谓规范 / 标题表达风格 / 信息密度原则 / 禁用表达 / 跨屏重复检查结果。

（兼容保留：`screens[].{title, summary, sellingPoint, copywriting, promptDirectives[], negativeConstraints[]}`；字段值域沿用现有 outputSchema，不改运行时结构。）

## 边界
**提示词注入与内容隔离（正式 §十三）**：内部分析/备选文案/质检规则/完整规则正文不得整体注入最终提示词。最终提示词只允许：当前屏最终确认文案/必要文字层级/必要排版与文字位置要求/必要文字可读性要求/与画面协同所需简短说明/必要事实表达限制。未采用备选文案/内部分析/其他屏文案/完整文案策略不得注入。**三类区分**：文案本身是画面中需呈现的文字；排版要求是图像模型需执行的视觉指令；内部策划分析不属于以上两者。不得把"主标题""辅助说明""卖点策划"等内部字段名当画面可见文字。

（兼容保留旧边界：只做文案与版式结构，不改前端参数 UI、不新增必填设置、不做视觉构图→visual-art-direction、不改 G-2 词表；不改运行时。）

## 冲突处理
（正式 §十四失败处理 + 旧冲突规则合并）
商品事实不足/本屏内容任务不清晰/用户文案与事实冲突/画面无法承载全部文字时：1 优先保留已确认事实；2 不编造内容填补空缺；3 删除低价值文字；4 简化表达；5 保留用户明确要求；6 必要时反馈上游问题；7 不擅自改变整套营销方向或详情叙事。除非信息确实不可替代否则不阻塞生成。
- （旧）文案诱感 vs 真实性：真实性优先删无证据表达；用户 copywriting 档位 vs 策划更优表达：尊重用户档位、策划在该档内优化；首屏"不写死标题" vs 平台模板习惯：按商品属性拟标题不套固定句式。

## 测试案例
**质量验收 20 条（§十五）**：1 因实际文案需求触发；2 只处理当前屏需要文字；3 准确承接营销策划与叙事任务；4 基于已确认事实；5 符合消费者语言习惯；6 避免空洞参数罗列；7 避免生硬说明书语言；8 避免过度营销夸张承诺；9 避免编造数据认证用户评价；10 标题清晰且与内容一致；11 卖点有明确事实依据；12 避免近义卖点重复；13 避免强制固定标题加卖点结构；14 按画面空间控制文字密度；15 与视觉导演方案协同；16 避免文字与画面互相重复或冲突；17 尊重用户指定文案和表达风格；18 遵守行业专项表达边界；19 只将当前屏必要文案注入提示词；20 避免内部分析与备选文案污染提示词。

（兼容保留旧测试案例：案例 F 营销表达——只给包装参数→文案做事实→需求→利益→表达非参数罗列；案例 B 资料不足——单图清洗剂文案保守不写虚构功效；负向——两屏 summary/sellingPoint 语义几乎相同判复述。）

**最终执行原则（§十六）**：文案策划不是把商品功能改写成更好听的句子，而是把已确认的商品价值转化为消费者容易理解、愿意阅读、与画面有效协同的文字表达——不虚构事实、不夸大功效、不堆砌参数、不强制每屏标题和多个卖点、不机械重复营销表达、不让文案越权改变营销策略和详情叙事、不让内部策划内容污染最终生图提示词。每一句进入画面的文字都必须有明确的表达价值。
