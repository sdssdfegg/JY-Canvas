## 4. 评价维度（六项，逐项记录；V219 §4.3）

每项 1–5 分 + 严重错误标记：

1. 商品理解；2. 营销策划；3. 叙事逻辑；4. 视觉创意；5. 提示词质量；6. 真实性。

> 🔴 **严重错误不可被其它高分抵消**：商品事实错误、虚假功效、行业错误（方案 §10.3 / V219 §4.3）。命中任一即整组不合格，写入 `quality-result.criticalFlags`。
